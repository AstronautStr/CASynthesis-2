# Scan — «волны по пластине» (scanned synthesis, ПРЕДЛОЖЕНИЕ)

#proposal

## Идея
Существо — упругая поверхность, на которой живёт МЕДЛЕННОЕ поле u (рябь
герцовых частот, видимая глазом). Звук = форма этого поля, считанная вдоль пути
обхода живых клеток f0 раз в секунду (канон: Verplank/Mathews/Shaw «Scanned
Synthesis», ICMC 2000; исполнитель = КА). Покой = устойчивый «тон покоя» формы;
событие автомата впрыскивает горб → круги расходятся → тембр расцветает и
успокаивается.

## Чем отличается от Laplace
Laplace: форма → **статичный** спектр (события меняют только баланс — см. слабость
[[Dyn]]). Scan: форма → **эволюционирующая волна** — спектральный ПОТОК, главная
нетронутая ось тембра. Событийная энергия уходит в движение поля, а не в тень
амплитуд.

## Архитектурный факт
`analyse()` уже зовётся каждый кадр (~60 fps) — движку не нужен отдельный
аудио-путь: scanned-синтез пере-выражается спектрально (freqs = k·f0 гармоники,
amps = |rFFT(скан поля вдоль пути)| пер-кадрово). Гипотеза (слуховая, проверить):
отброс фазы гармоник не убьёт характер.
