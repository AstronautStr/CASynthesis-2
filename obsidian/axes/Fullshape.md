# fullshape — граф по всей форме (снятие окна 8×8)

#implemented #listening-queue

## Зачем появилась развилка
`extract(sub, 8)` кропал объект до окна 8×8 вокруг центроида — крупная форма
«слышалась» только центром, периферия терялась (при том что сегментация видит
весь объект). Развилка заведена 2026-06-17 («extract 8×8 ограничивает разрешение
формы»).

## Механизм
Лапласов путь ядра уже агностичен к размеру входа (граф строится по живым
клеткам как есть) — fullshape = **перестать обрезать**: подавать тайтовую маску
`sub` напрямую. Флаг `fullshape` в `map_laplacian` (дефолт ядра False =
бит-в-бит; реестровый Laplacian = **True**). Потолок `MAX_LAPLACIAN_NODES=256`
с детерминированной решёточной децимацией (`eigh` — O(V³)). Гармонические движки
остаются на 8×8 (маркер в реестре, ветвление на вызове).
