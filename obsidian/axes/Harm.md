# harm — гармоническое квантование (металл → хор → гармоника)

#accepted

## Зачем появилась развилка
На низких нотах Laplace-металл давал «грязь» — диагноз: **roughness** некратных
партиалов, скучивающихся в критических полосах (Пломп–Левельт), не клиппинг и не
алиасинг. Нужен был непрерывный рычаг между «металлом как фишкой» и «чистотой
гармонической решётки», не убивающий приём.

## Механизм
Притяжение частотных отношений мод к ближайшему целому:
`r' = (1−harm)·r + harm·round(r)`, `r_k = freq_k/f0`. Трогает ТОЛЬКО частоты;
форма по-прежнему выбирает, какие гармоники заняты (round к ближайшей, не 1..n).
Дефолт 0 = бит-в-бит.

## Вердикт
**Принят на слух 2026-06-22**: harm→1 убирает «грязь» низов (диагноз roughness
подтверждён), металл сохраняется на средних значениях; различимость форм у
harm=1 косвенно ок. Кандидат с критикой: регистро-зависимая привязка harm
(низ к 1, верх вольнее — «хор»).
