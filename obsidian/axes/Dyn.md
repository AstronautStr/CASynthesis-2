# dyn — динамическое возбуждение (спектральный канал ветки ДИНАМИКА)

#accepted #weak-lever

## Зачем появилась развилка
Статическое `e = deg` наследует симметрию формы → половина мод симметричных
существ структурно молчит, и существо звучит одинаково независимо от того, что
с ним происходит. Идея: `e` из **событий поколения** — существо звучит тем, что
с ним случилось («тембровая походка», события открывают запертые моды).

## Механизм
`events_field(prev, new)`: рождения = 1.0, живая 8-кромка смертей = `W_WOUND=0.7`,
вклады суммируются; держится между шагами. В shape-ветке ядра:
`e = (1−dyn)·ê_deg + dyn·ê_ev` (юнит-нормировка до бленда, fallback на deg при
нуле событий). Только амплитуды; дефолт 0 = бит-в-бит.

## Вердикт (слуховой гейт ЗАКРЫТ 2026-07-06)
**Слабый рычаг.** В самом благоприятном режиме (shape=1, dyn 0↔1, все кейсы
ab_bench включая коллизию) разница едва слышна, хотя спектрально видна. Причина
структурная: dyn модулирует только **баланс амплитуд при фиксированных частотах**
— канал низкой перцептивной чувствительности (ухо читает Laplace-металл по
набору частот). Наблюдение: инертен на симметричном материале (проекция
сокращается, Σ⟨e,φ⟩=0).

**Это вердикт рычагу, не ветке**: dyn остаётся «тонкой краской» (дефолт 0),
НЕ полируется; тот же `events_field` направлен в громкостный канал → [[Acc]],
рычаги синергичны на одном событии.
