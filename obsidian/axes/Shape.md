# shape — формозависимые амплитуды (краевое возбуждение)

#accepted

## Зачем появилась развилка
Крутилки spread/alpha дали яркость, но амплитуды мод оставались «слепыми» к форме
(rolloff `1/i^α` по номеру моды) — крупные формы звучали похоже. Нужен был канал,
через который **сама форма** решает, какие моды громкие.

## Механизм
`amps = (1−shape)·rolloff + shape·|⟨e, φ_k⟩|`, где `e_i = deg_i` (число живых
8-соседей = диагональ L) — **краевое возбуждение**: однородная внутренность
(deg=8) ортогональна звучащим модам, «форма звучит своей границей». Частоты не
затрагиваются. Дефолт 0 = бит-в-бит baseline.

## Вердикт
**Принят на слух 2026-06-22**: различает крупные формы даже под окном 8×8; f0
держится при shape=max. Биения при сломе симметрии — природа приёма, не дефект.
Нули проекций на симметричных формах допустимы (симметричная пластина не звенит
антисимметричной модой) — см. панель D обучалки `laplacian_explainer/`.
