## 1. Источник возбуждения

В Objects добавить выбор **Events: Both / Births / Deaths**. Сохранённые сцены без параметра и прежний default — Both. Births и Deaths — положительные события; смерть не превращать в отрицательный импульс.

Для продолжающейся фигуры:

```text
B = новые живые клетки внутри K_cur
D = исчезнувшие клетки внутри K_prev
Both: e = |B| + |D|        # прежний тракт
Births: e = |B|
Deaths: e = |D|
a = e / (e + 2)
```

K — прежняя маска Own или Disk. Выбор меняет источник новых импульсов; спектральный закон, Attack, Decay и дозвучивание сохраняются. Переключение само импульса не создаёт. Both должен побайтно воспроизводить прежний путь, включая нынешний жизненный цикл банков.

В Births новые банки получают только реальные рождения. В Deaths возникновение банка само не даёт импульса. Для исчезнувшей фигуры/старых банков при split/merge в Deaths один раз обработать смерти в их прежней маске и на прежних резонансах; дать последнему импульсу и его отклику закончиться. Не потерять этот импульс при переводе в tail и не повторять его на следующих блоках. В E1 такой развилки нет: фигура сохраняет один банк весь период. Способ хранения последнего возбуждения — Developer.

`dyn` — отдельный существующий канал спектральных весов, не часть селектора Events. В обоих новых опытах `dyn=0`, чтобы второй тип событий не участвовал через этот канал. При дальнейшем ручном включении `dyn` он сохраняет прежний явно отдельный смысл.

## 2. Распределение нового импульса между модами

Добавить **Excitation: Uniform / Birth position**. Uniform — прежний одинаковый вход во все моды. Первая пространственная проба Birth position определена для **Events=Births, Detector=Own, Spectrum=Laplace, full=on**. Режим явно показывать как такой набор условий; не подменять неподдерживаемое сочетание общим импульсом. Способ выбора/отображения — Developer. Это проба собственной фигуры; передачу спектра соседа и пространственную обработку смертей здесь не вводим.

Лапласиан, выбор частот, `part`, `spread`, `harm` и выходные веса те же. Для выбранных мод дополнительно нужны собственные векторы в согласованном порядке клеток, даже при `shape=0`. Рождения брать из реального перехода КА, без `wound edge` существующего `events_field`.

**Закон первой пробы — неотрицательная сила участия клетки.** Это выбранный Researcher способ проверить спектральную избирательность; не знаковая сумма сил из физической модели пластины. Совместные рождения складываются по квадратам участия. Знак/противофазное сложение событий отдельным новым фактором не вводятся.

Для нормированных собственных векторов, выбранной моды j и множества рождений B в текущей фигуре:

```text
p_j = sum_{i in B} phi_j(i)^2
b_j = sqrt(m * p_j / sum_l p_l)        # m — число выбранных звучащих мод
delta_j = a * b_j
```

Для Uniform `b_j=1`. В обоих случаях `sum(delta_j^2)=m*a^2`: одинаковая норма входного пакета, разное распределение между модами. Это нормировка распределения нового пакета, не выравнивание текущего аудиовыхода и не обещание одинаковой громкости. Если B пусто — пакета нет. Если сумма p_j ≤1e−12 — выбранные моды пакета не получают; не заменять нулевое участие общим ударом, такой случай отразить в диагностике.

При кратных собственных значениях использовать инвариант к повороту базиса внутри всего кратного подпространства: для группы Q ранга d у каждой выбранной из неё моды `p_j = sum_{i in B} sum_{k in Q} phi_k(i)^2 / d`. Q включает всю группу до отбора `part/spread`, даже если отобрана часть группы. Допуск группы: `abs(lambda_k-lambda_j) <= 1e-8*max(1,abs(lambda_j))`. Проверить и знаковую, и базисную инвариантность. В preflight использована эта формула.

Величина delta_j поступает **на вход соответствующего резонатора** через прежний импульс и Attack. Нужны состояния возбуждения, сохраняющие вклад каждого прошлого пакета с его коэффициентами. Не реализовывать через замену текущих выходных весов: она переокрасит уже звучащие хвосты и воспроизведёт другой опыт. Последующие retune и жизнь/исчезновение мод следуют нынешней модели Objects. В M1 `shape=alpha=dyn=0` на обеих сторонах: выходные веса равны, эффект не продублирован прежней проекцией `dyn`.

### 5.1. Ручка и область действия

Добавить параметр **Birth strength** (`birth_strength`), непрерывный линейный диапазон **0…4**, default **1**. При отсутствии ключа в старых сценах/снимках — 1. Значения должны быть конечными и внутри диапазона. На панели показать текущее число и краткий смысл: «0 = Uniform; 1 = original; >1 = stronger selection». Ручка доступна при Excitation=Birth position; в Uniform хранится, но не действует и отмечена неактивной. Общий default Excitation остаётся Uniform.

Сохранить текущую область Birth position: Births + Own + Laplace + full. Значение 0 не обходит это условие. Возможность Disk — отдельная ещё не выбранная задача; подсказка условия должна оставаться видимой. Цель M2 — изолировать силу влияния без изменения детектора, поля, числа частот или дозвучивания.

### 5.2. Точный закон

`b_j` — исходные коэффициенты раздела 2 (до умножения на `a`), `m` — число выбранных звучащих мод, `s` — Birth strength. События, скалярная сила `a=e/(e+2)`, частоты, выходные веса и группировка кратных значений прежние. Новая ручка меняет только распределение очередного входного пакета:

```text
s = 0:       c_j = 1                         # прямой прежний Uniform
0 < s < 1:   v_j = (1-s) + s*b_j
             c_j = sqrt(m) * v_j / sqrt(sum_l v_l^2)
s = 1:       c_j = b_j                       # вернуть прежние b без перенормировки
1 < s <= 4:  v_j = b_j^s
             c_j = sqrt(m) * v_j / sqrt(sum_l v_l^2)

delta_j = a * c_j
```

Ветку `s=0` проводить через существующий Uniform-тракт; `s=1` — через существующий Birth position-тракт без новых арифметических операций над коэффициентами. Это обеспечивает возможность побайтной совместимости, которую необходимо проверить реальным рендером. В промежуточных значениях плавно вводится исходное распределение; выше 1 усиливаются отношения его коэффициентов. Простое умножение всех `b_j` на `s` не соответствует заданию.

**Краевые случаи:**

- Нет рождений или нет звучащих мод — нового пакета нет при любом s.
- При реальных рождениях и `s=0` пакет Uniform не требует ненулевого пространственного участия. При `s>0` исходное `sum p <= 1e-12` сохраняет прежнее поведение: пакета нет, случай отражён в диагностике. Это намеренное различие нулевой силы и пространственного режима; в M1 такого нулевого участия при рождениях нет. Не применять смесь к нулевому пространственному пакету и не восстанавливать его неявно.
- Точный ноль отдельного коэффициента сохраняется при s>=1; при 0<s<1 его вклад постепенно появляется из Uniform. Не вводить новый epsilon, обрезание малых b или знак импульса. Все коэффициенты неотрицательны.
- Равные b остаются равными; при одной моде c=1. Усиление не создаёт различий между одинаковыми профилями. Для ненулевого пакета `sum c_j^2=m`, `sum delta_j^2=m*a^2` с погрешностью вычисления. Это не нормировка аудиовыхода и не обещание равной громкости.

Контрольный пример: фаза 2, 16 клеток Jam, три рождения, частоты ≈110 / 544.983 / 659.752 Hz:

| s | c₁ | c₂ | c₃ |
|---|---:|---:|---:|
| 0 | 1.000000 | 1.000000 | 1.000000 |
| 0.5 | 0.901214 | 0.861881 | 1.202071 |
| 1 | 0.781500 | 0.703746 | 1.376227 |
| 2 | 0.515832 | 0.418295 | 1.599671 |
| 4 | 0.178722 | 0.117524 | 1.718792 |

Полные числа и остальные фазы — в preflight. Проверено только преобразование существующих фазовых коэффициентов, не новый DSP и не слышимость.

`delta_j` поступают через прежний Attack в состояния возбуждения соответствующих мод. Смена s действует только на следующие пакеты: не создаёт события, не обнуляет и не переумножает старые импульсы или хвосты. При переходах через 0/1 сохранить накопленные состояния обоих существующих путей; не пересоздавать банки. Последующие перестройки частот и жизненный цикл мод прежние. Параметр сохраняется в сценах, журнале команд, снимках и копировании стороны; старые снимки импортируются с s=1. Версионирование состояния и звукового набора должно честно учитывать новый параметр.
