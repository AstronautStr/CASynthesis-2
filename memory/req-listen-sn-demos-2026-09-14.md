## Что подготовлено — Developer

- Два входа `run_scan_demo.bat`, `run_network_demo.bat` открывают стенд на демо-сцене с отдельными каталогами `lab_catalog/sn_demos_2026_09_14/scan/` и `.../network/` (кнопка **Catalog** в стенде). Каталог собирается один раз командой `python demos/build_sn_demos.py` (каталог — пользовательские данные, не в Git; если он уже есть, сборщик отказывается его трогать). Поля, Python и JSON пользователь не готовит.
- В каталоге записи перечислены сверху вниз в порядке шагов; открыть запись = выбрать её и нажать **Continue (this version)**.
- Все записи содержат обе дорожки, монитор и точное конечное состояние. У статичных случаев Continue сохраняет работающий звук и остановленный КА (кнопка Pause CA подсвечена); это не остановленный/беззвучный стенд.
- Записи короткие: 8 с для статики, 12 с для эволюции (Pulsar, 2 шага/с). Постоянные уровни: Scan `Level` = +6 dB, Network = +3 dB (RMS выровнен с Laplace на Pulsar, одна поправка на движок); оригинальные WAV сохранены как прозвучали. Внутри сравнения только указанное различие.
- `S-path` — F1, `Width` 1.5, `Smooth`, радиусы 0.8. `S-surface` — Smooth/Distance, Raster, width 1.5. `N-links` — F5 верхняя/нижняя половина, `Coupling` 0/2, остальное одинаково. Эволюционные случаи — F3 Pulsar.
- Все кнопки проверены агентом (headless). Известный «тихий» случай: эллипс/Лиссажу радиуса 0.8 обходят Pulsar по кругу и читают только хвосты сглаживания — поэтому F3 подготовлен только с Raster; такой записи в каталоге нет.

## 1. Scan: что даёт путь и что даёт поверхность

Запустить `run_scan_demo.bat`, нажать **Catalog**, выбрать запись **S-path: Ellipse / Lissajous**, нажать **Continue (this version)**. КА уже на паузе, звук идёт. Нажимать **1 / 2**, чтобы слушать A/B: поверхность и рисунок одинаковые, меняется только маршрут; он нарисован поверх клеток (точка со стрелкой = начало и направление). Затем открыть **S-path: Ellipse / Raster** и так же сравнить. Не менять ширину/уровень между сторонами.

Открыть **S-surface: Smooth / Distance (F1)**, Continue, снова 1 / 2. Теперь маршрут один — Raster, меняется способ превращения рисунка в поверхность. При желании открыть **S-surface: Smooth / Distance (F2)** с теми же настройками и сравнить со звуком F1.

**Что оценить:** это разные характеры или преимущественно громкость/яркость? Есть ли путь, с которым понятнее, какую часть рисунка слышишь? Различие путей само по себе ещё не отвечает, разнообразно ли звучат разные поля.

## 2. Network: влияют ли именно связи, которыми управляет поле

Запустить `run_network_demo.bat`, **Catalog**, запись **N-links: independent / connected (top)**, Continue. A — четыре независимых генератора (`Coupling` 0), B — связанные (`Coupling` 2); заполнена верхняя половина поля. Сравнить 1 / 2. Открыть **N-links: independent / connected (bottom)**: настройки и число клеток те же, заполнена нижняя половина. Можно сравнить B в двух записях, чтобы услышать влияние расположения клеток при неизменной Coupling. Шесть кругов на поле — области чтения связей (`j>i` = j модулирует i), полоски в панели — текущие глубины W.

Открыть **N-frozen: live / frozen links**, Continue, послушать 10–15 секунд с переключением A/B. КА эволюционирует на обеих сторонах; на A он обновляет связи, на B связи сохранены от начального поля (`Frozen links` on). Затем нажать Space: рисунок остановится, фаза звука продолжит идти.

**Что оценить:** меняется ли характер связанной сети между полями при неизменной глубине? Слышна ли эволюция управления связями? Нравится ли хотя бы один результат настолько, чтобы его развивать? Рост эффектности при повороте одной Coupling без заметного вклада поля не считается успехом маппинга.

## 3. Оба метода против Laplace и одна собственная правка

В каждом демо открыть основную запись **S-Laplace: Laplacian / Scan Smooth Raster** / **N-Laplace: Laplacian / Network**, Continue. A — Laplace (`shape=1, harm=0`), B — новый метод; КА идёт (Pulsar). Сравнить 1 / 2. Эти пары оценивают весь метод: у него меняются и чтение поля, и звукообразование. У Laplace-контроля есть варианты **S-Laplace (harm=1)** / **N-Laplace (harm=1)** — различие только гармоничности не должно решать весь вывод; для Scan есть ещё **S-Laplace (Distance)**.

У выбранного нового метода нажать Space, чтобы остановить КА, и стереть/добавить несколько клеток в видимой области чтения. В Scan для простой проверки можно выбрать Raster, читающий всё поле. В Network ориентироваться на показанные области связей. Сохранить понравившееся через **Save**; открыть эту запись в **Catalog → Continue**, изменить её дальше и сохранить ветку. Точное совпадение продолжения уже проверяет Developer — пользователь здесь проверяет возможность пользоваться находкой.

**Что оценить:** появился ли звук или способ его изменения, которого не хватало в Laplace? Удалось ли намеренно изменить что-то слышимое? Если есть только отдельная находка, её тоже сохраняем; не требуется доказывать освоенность инструмента за один сеанс.

## Как зафиксировать впечатление

Достаточно свободного ответа по каждому методу: «хочу исследовать дальше», «есть одна находка», «пока всё похоже», «поле почти не слышно», «трудно управлять» — и названия записи, если что-то хочется сохранить. Нет обязательной анкеты, численного рейтинга или автоматического вывода о художественном успехе. Можно начать с одного шага и вернуться к остальным позже.
