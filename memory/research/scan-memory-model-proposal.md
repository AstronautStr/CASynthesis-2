# Scan Memory — модель отложенного предложения

2026-09-09. **ОТЛОЖЕНО, НЕ ЧАСТЬ S3.** Модель [исследовательского предложения](scan-memory-proposal.md), исключённого пользователем из разработки стенда. Не реализована и не прослушана; численная проба ниже не подтверждает художественную полезность. Не использовать как требования к архитектуре текущего спринта.

## 1. Поле и память

G — бинарное поле в float64; U — вещественная память того же размера. H(X) = `scipy.ndimage.gaussian_filter(X, sigma=1.0, mode='wrap', truncate=4.0)`. На инициализации U=0, P=H(G). Исходное заполнение не является событием рождения.

На каждом реальном изменении поля на границе блока:

`U += H(float64(G_new) - float64(G_old)); P = H(G_new)`.

Вычитать после преобразования в знаковый/вещественный тип, не в uint8. Каждое изменение учитывается один раз. Несколько событий на одной границе складываются в порядке общего журнала; без промежуточного рендера их разности телескопируются. Не использовать старое положительное поле возбуждения dyn. Вызовы обновления настроек или повторного анализа с тем же G не создают события.

Каждый звуковой блок начинается с уже применённых событий. Целевая поверхность этого блока — `S=P + memory*U`. После его рендера `U *= exp(-BLOCK/(SR*decay_s))`. Никакого второго затухания на тике КА или ручке. При Pause CA звуковые блоки продолжаются; Stop прекращает звук и сбрасывает состояние. При memory=0 U также вычисляется. Изменение decay_s задаёт только дальнейшее затухание.

## 2. Чтение и ограничение полосы

N=2048, theta_j=2πj/N. Центр `(cy,cx)=((rows-1)/2,(cols-1)/2)`, радиус `R=min(rows,cols)/4` (для сцены 32×32 R=8).

`y_j=cy+R*sin(theta_j); x_j=cx+R*cos(theta_j)`.

Прочитать S билинейно в этих координатах, например `map_coordinates(S,[y,x],order=1,mode='wrap',prefilter=False)`. Траектория не зависит от числа живых клеток. Её же точки передать визуальной подсказке. Фигуры вдали от траектории влияют слабо или не влияют — это ограничение этой пробы.

Полученную таблицу преобразовать `rfft`; обнулить DC и коэффициенты с индексом выше `K=min(N//2-1, floor(0.45*SR/f0))`, затем `irfft(...,n=N)`. Результат Q — целевая таблица блока. При K<1 Q=0. Сохранять комплексные коэффициенты, не заменять их модулями и не ограничивать нынешними 20 партиалами. Для f0=110, SR=44100 K=180. Это ограничение полосы статической таблицы, не доказательство полного отсутствия любых побочных полос при модуляции.

## 3. Причинное сглаживание и звук

W — состояние сглаженной таблицы. На инициализации W=Q, вычисленной из исходного P при U=0; phase=0. Для отсчётов n=0..BLOCK-1 целевая Q неизменна внутри блока:

```
alpha_n = exp(-(n+1)/(0.020*SR))
p_n = (phase + n*f0/SR) mod 1
wave[n] = alpha_n*lookup(W,p_n) + (1-alpha_n)*lookup(Q,p_n)
W = exp(-BLOCK/(0.020*SR))*W + (1-exp(-BLOCK/(0.020*SR)))*Q
phase = (phase + BLOCK*f0/SR) mod 1
```

`lookup` — периодическая линейная интерполяция таблицы по фазе. Это точное сглаживание таблицы для удерживаемой в блоке цели; не интерполяция с будущим поколением. Достаточно двух lookup на отсчёт и одного обновления W на блок; создавать массив размера N×BLOCK не требуется.

Выход до квантования: `8 * gain[n] * wave[n]`, два одинаковых канала. gain — текущий общий `MASTER_GAIN * vol * scene.level` с существующим сглаживанием изменения громкости. У нового бэкенда на инициализации/сбросе gain_prev=0: первый блок поднимает gain по той же кривой сглаживания, чтобы старт таблицы с ненулевого значения не давал скачка уровня. Множитель 8 постоянен и одинаков для A/B; он компенсирует малый уровень сканируемой поверхности. Нет покадровой нормировки, компрессии и перцептивного выравнивания A/B. Квантование в int16 и диагностика peak/clip совместимы с контейнером Block; клиппинг не скрывать. Сценарий ниже рассчитан при постоянном gain, без начального подъёма; этот подъём интеграционный тест учитывает отдельно. При произвольном редактировании сохраняется диагностика перегрузки.

GEN/VOICE-огибающие SlotPool к этому новому методу не применяются. Само изменение поля и фильтр таблицы задают его динамику. Транспортный fade и A/B-crossfade остаются отдельными операциями монитора S2.

## 4. Что допустимо оптимизировать

Кэшировать P до изменения G, координаты, интерполяционные веса и преобразование неизменной части. Память и временное сглаживание обязательны. При желании хранить память в линейно спроецированном представлении — сначала доказать тестом совпадение с полевой формой выше; это не условие первого прототипа. В S3 контрольный шаг равен фактическому аудиоблоку, а не предложенным раньше 200 Гц: так вводится одна временная сетка в принятый исполнитель.

Сцена из ТЗ; SR=44100, BLOCK=352, f0=110, sigma=1, tau=2, vol=0.7, MASTER_GAIN=0.04. Первые 2 с КА идёт 4 поколения/с. На первой границе блока после 2 с (сэмпл 88352, 2.003446712 с) КА заморожен, четыре левые клетки удалены одним событием; затем без событий до 8 с. Начальное W из исходного поля, phase=0. Значения ниже относятся к float-выходу до int16 и транспортных fade.
