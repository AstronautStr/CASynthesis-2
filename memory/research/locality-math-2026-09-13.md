# Локальность, соразмерность и хаос: математические ориентиры

2026-09-13. **Исследовательская заметка, не принятое формальное требование.** Вынесена из [центральных принципов](sonification-criteria-2026-09-13.md): пользователь оставляет в них только качества создаваемого синтезатора.

## Близкие входы и близкие результаты

Непрерывность формализует зависимость «достаточно малое изменение входа даёт малое изменение выхода». Равномерная непрерывность позволяет выбрать допустимый размер изменения входа одинаково для всей рассматриваемой области. Более сильное количественное условие — **условие Липшица**:

`d_sound(F(x), F(y)) ≤ L · d_field(x, y)`.

Здесь F — выбранное преобразование, расстояния описывают различия полей и звуковых результатов, L ограничивает усиление различий. Это достаточная математическая форма для обсуждаемой локальности; она не следует автоматически из бытового слова «соразмерность». Определения: [лекции ETH Zürich, Analysis II, §9.2.2, определение 9.54, PDF с. 23](https://metaphor.ethz.ch/x/2024/fs/401-1262-07L/notes/Analysis_II_Script_v1.pdf#page=23).

Для сравнения звуков нужно оговорить прочие условия: настройки, горизонт рендера и, если требуется, исходное состояние звукового процесса. Запись F не вводит обязательный движок без памяти.

## Почему это не противоположность хаосу

Чувствительность к начальным условиям относится к расхождению траекторий при дальнейшем развитии системы. Один шаг может быть плавным и ограниченным по Липшицу, а последовательность шагов — усиливать первоначальную разницу. Из границы L на один шаг получается оценка L^n на n шагов; при L > 1 такая оценка не гарантирует сохранения близости. Эта оценка сама по себе также не доказывает хаос. Обзор динамического смысла чувствительности: [MIT, Nonlinear Dynamics: Chaos, лекция 1](https://live.ocw.mit.edu/courses/12-006j-nonlinear-dynamics-chaos-fall-2022/mit12_006jf22_lec1.pdf).

Иной запрос — чтобы достаточно близкие начальные состояния оставались близкими к выбранному движению при всех последующих временах — относится к **устойчивости по Ляпунову**. Стандартное определение для равновесия и его отличие от асимптотической устойчивости изложены в [MIT, Lyapunov Analysis](https://underactuated.mit.edu/lyapunov.html). Не смешивать устойчивость отдельного равновесия или множества с утверждением об отсутствии хаоса во всей системе.

Для CASynth пока обсуждали прежде всего чувствительность преобразования поля в звук. Расхождение дальнейших эволюций почти одинаковых полей пользователь допускает. Поэтому запрещать хаос или требовать устойчивости всех траекторий на основании слова «локальность» нельзя.

## Обе стороны соразмерности

Если дополнительно потребовать сохранения различий снизу, возможна форма

`c · d_field(x, y) ≤ d_sound(F(x), F(y)) ≤ L · d_field(x, y)`, где `0 < c ≤ L`.

Это **би-липшицево отображение на образ**: оно ограничивает и растяжение, и сжатие расстояний. Такая формализация существенно сильнее сохранения малости изменений; при настоящих метриках она требует инъективности. Пример использования и определений в математическом исследовании: [Bate, Garcia Pulido, Bi-Lipschitz embeddings…](https://pmc.ncbi.nlm.nih.gov/articles/PMC11438830/).

Это кандидат на обсуждение, не выбранный критерий. В частности, если переносы фигуры решим считать эквивалентными, надо сначала учесть эту эквивалентность в пространстве входов/расстоянии; требование к сырым битовым полям будет другим.

## Что ещё нужно определить

- Какие различия полей существенны: число изменённых клеток, геометрия, события или другое представление. Решения пока нет.
- Что именно сравниваем в звуке и на каком временном отрезке. Численная разность PCM не назначается автоматически расстоянием по характеру звучания.
- Насколько малой должна быть допустимая чувствительность и на какой области это требуется.

Отдельная математическая оговорка (следствие определений): на конечном наборе полей с настоящей метрикой любое отображение в метрическое пространство имеет некоторую конечную константу Липшица — достаточно взять максимум отношения выходного и входного расстояний по различным парам. Поэтому само существование L почти ничего не проверяет. Нужны осмысленные расстояния и содержательное ограничение на величину L; для непрерывности конечного дискретного набора проблема ещё очевиднее.

Ни одно из этих условий само по себе не задаёт глубину или художественную ценность синтезатора.
