# Scan Memory — отложенный сценарий прослушивания

2026-09-09. **ОТЛОЖЕНО, НЕ ПРИЁМКА S3.** Сценарий сохранён для [исследовательского предложения](scan-memory-proposal.md); оно не реализовано и не входит в разработку стенда. Следующие шаги пока невыполнимы и пользователю не назначены. В случае отдельного возвращения к исследованию потребуется подготовить запуск с `scan_memory_ab.json`.

Исходно: A memory=0; B memory=1; обе decay_s=2 с. Слева отмечен блок 2×2, справа блинкер; линия показывает, где считывается звук. Параметры и клетки уже выставлены.

1. **Start → A/B.** Послушай обе стороны несколько секунд. Пока достаточно заметить, есть ли разница; маленькая разница ещё не означает неисправность.
2. **Space (Pause CA) → сотри отмеченный блок слева ПКМ → 1/2 (A/B).** Удалить четыре отмеченные клетки коротким мазком. На B ожидается затухающий вклад удалённого участка; A быстрее переходит к звуку оставшейся фигуры. Весь звук гаснуть не обязан: справа остаётся живая фигура.
3. **На B поставь decay_s=4 → Restart (R) → повтори стирание на паузе.** Оцени, помогает ли более длинная память исследовать звук или ощущается лишь как ненужный хвост.

Ответа одной строкой достаточно: **«слышу / не слышу; интересно / неинтересно; неудобно вот это»**. Разницу по числам, правильность затухания и повторяемость уже проверяет разработчик. Для возврата к исходным настройкам есть Factory A+B и Restart.
