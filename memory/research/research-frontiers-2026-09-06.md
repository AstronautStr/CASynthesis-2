## A. Критика предыдущих циклов

### A.1 `frontiers-2026-07-02`

**§1 Adeli et al. 2014 как калибровочная таблица.** [Р] верно; [П] под новой спиной — **не
критерий**. Остаётся зерно: «f0 не связался с размером» — предупреждение для оси «размер →
регистр», если когда-нибудь ослабим якорь (§C.1 М3). Таксономия Спенса — гигиена.

**§2 Байесовский каузальный вывод как целевая функция.** [Р] верно (Körding et al. 2007). [П]
— под новой спиной это *ограничение*, не направление: окно интеграции ~100–300 мс требует,
чтобы реакция на правку шла не по тику (250 мс при 4 пок/с), а немедленно — и она идёт
(`analyse()` каждый кадр + lookahead 40 мс); событие автомата синхронно с картинкой по
построению. Шутц–Липскомб — гигиена протокола и ресурс (B8).

**§5 «Что спектр всё-таки слышит».** [Р] верно (V, E = ½Σλ, число компонент, остовные деревья
по Кирхгофу). Оговорка: число треугольников определяет спектр **смежности** (tr A³), не
Лапласиана. «Дыра = формант» — ручная фича поверх (узел `a_topo`), не «светлая сторона Каца».

**§6 BGS / статистика спейсингов как ось порядок↔хаос.** [Р] верно для систем с сотнями уровней
после unfolding. [П] — **не применимо**: у объектов зоопарка 3–30 мод; гистограмма спейсингов
одного объекта пуста, а пулинг по зоопарку — не свойство формы. Прямоугольные куски решётки
(king's graph) сепарабельны: λ = a_k + a_m + a_k·a_m по путевым модам → пуассонов спектр *по
построению*, не потому что «форма регулярна». Точные вырождения симметричных форм (биения при
сломе симметрии, [С]) — теория групп, не RMT. «У хаоса один тембр» **не следует**:
универсальность RMT — про *флуктуации*, тембр — про сглаженную плотность и амплитуды. Настоящее
объяснение «библиотека звучит одинаково» — §C.1, измерено на самой библиотеке.

**§7 Квантовые графы = «тон и эхо из одного объекта».** [Р] формула следа верна (Kottos &
Smilansky 1997). [П] — ошибка масштаба. На **равнорёберном** графе (стандартные условия в
вершинах) спектр квантового графа сводится к комбинаторному: k — собственное ⇔ cos(kℓ) ∈
spec(D⁻¹A) (von Below 1985; Cattaneo 1997 — «соответствие Каттанео» [оба веб-проверено];
учебник Berkolaiko & Kuchment 2013). Следствие:
k = (±arccos μ + 2πm)/ℓ — **каждое μ порождает гребёнку с периодом 2π/ℓ**, одинаковым для
всех форм. «Эхо формы» = комб с задержкой ℓ/c; формозависимое сидит в смещениях arccos μ, т.е.
в спектре «брата Лапласиана» (`a_lapsibs`, «та же клетка»). Непериодический «зал» дают только
**несоизмеримые длины 1 : √2** орто/диагональных рёбер (орбиты a + b√2). Вывод: дверь B/S2/W
без геометрических длин — гармонический комб; с длинами — то, чьей дискретной тенью является
**взвешенный Лапласиан** `a_lap_w` (B1: по numpy чинит схлопывания и вырождения, но не
богатство в среднем).

**§8 Hodge / 1-Лапласиан как «второй независимый голос».** [Р] математика TSP верна (Lim 2020).
[П] — **оверклейм, ловится выкладкой и подтверждён численно.** L₀ = B₁B₁ᵀ, L₁^down = B₁ᵀB₁ →
ненулевые спектры совпадают (SVD). **[numpy]:** улей — L₀ и L₁ дают ТОЧНО [1, 1, 3, 3, 4];
то же на кольце 3×3 и пруде. Без 2-клеток «рёберный голос» = тот же набор частот + ядро
размерности β₁(граф) = E − V + c, которое на 8-связной решётке считает каждый треугольник:
**[numpy]** кольцо 3×3 (одна дыра формы) → β₁ = 5, улей → 1, пруд → 1 — β₁ графа дыр формы не
считает. С 2-клетками L₁ = L₁^down ⊕ L₁^up (B₁B₂ = 0) → spec(L₁)\{0} = spec(L₀)\{0} ∪
spec(L₂^down)\{0}: **новые частоты — только от Лапласиана граней**, а гармонические 1-формы
(циркуляции вокруг дыр) сидят на частоте **0 = тишина**. «Дырам — собственные голоса» неверно:
дыра — число, не мода. Поправка к зацепке про кубический комплекс: для 8-связных объектов Life
нужен **флаговый (клик-) комплекс** king's graph, не кубический — тьюб под 4-связностью
распадается на 4 изолированных вершины.

**§9a OT-морф.** [С] снят 2026-07-03. **§9b Громов–Вассерштейн.** Под новой спиной визуальная
метрика больше не цель; остаётся метрика на звуках — заменяется B7 + §C.3. GW на графах из 4–8
вершин вырожден. **§10 Спектральная хореография.** Верно; проверена (возрастные веса,
B-снято) — у осцилляторов доминирует дискретная смена множества узлов по фазам (A.6-10г), не
хореография собственных значений.

### A.6 Новые находки по существующей реализации **[numpy, оркестратор 2026-09-06]**

Это не критика документов, а факты о ядре, которых в памяти не было; они питают §C.

1. **`shape` инертен на регулярных графах.** У блока (K4), тьюба (C4), улья (C6), пруда (C8)
   все степени равны → e = deg ∝ константа = нулевой собственный вектор → все проекции 0 →
   фолбэк `proj = rolloff.copy()`. То есть на этих объектах `shape` не делает ничего.
2. **`shape=1` глушит якорь f0 у блинкера:** amps = [0, 1] — звучит только √3·f0 (≈951 центов
   над нотой). Известно из теста C (2026-06-18) как «допустимый нуль»; под сценарием это
   значит: библиотечные Blinker/Traffic light при shape=1 играют не ту высоту, что нажата
   (масштаб дефекта по всей библиотеке — п.10д).
3. **Пер-модовые амплитуды `shape` на вырожденных модах НЕ инвариантны к повороту:**
   T-тетромино, shape=1, третья мода: 0.180 (rot0), 0.188 (rot1/rot3), 0.707 (rot2) — ×4.
   Причина: внутри вырожденного подпространства (√2 дважды) базис `eigh` произволен;
   инвариантна лишь энергия подпространства. Decisions 2026-06-18 это предвидели и отложили
   пул энергии; 2026-06-22 деприоритизировали. Тест D инвариантности гонялся на
   *невырожденном* графе и этого не ловит. Симметричные формы — норма зоопарка → **заявленная
   инвариантность к повороту при shape>0 фактически нарушена.**
4. **Значение Фидлера λ₂ по зоопарку** (выбрасывается якорем): 0.0997 (пентадекатлон) … 4.0
   (блок); √λ₂ 0.316 … 2.0 — разброс ×6.3 «абсолютного тона», которого инструмент не слышит.
   Отношение верхней моды к f0: 1.0 (блок) … 8.16 (Figure-8).
5. **Коспектральных пар в зоопарке — 0** (A.2 §0).
6. **Аудит локальности** (один флип, fullshape, n=8, shape=0; d = RMS |log₂(r'/r)| по общим

## B. Новые направления

Для каждого: суть · почему отвечает новой спине · опора и сила · **МП** (минимальная проверка)
отдельно от **СИ** (стоимость интеграции) · что меняет решение · риск.

### B1. Геометрические веса `aniso` — вспомогательное: различимость линий и тетромино, не идентичность осцилляторов
_(развитие `a_lap_w`; понижено по A.6-10е)_

**Факты.** 8-связные графы компонент часто тривиальны (моя выкладка): блок = K4 (все моды на
f0), тьюб = C4, улей = C6, буханка = C7, пруд = C8, блинкер = P3; кольцо C_N: √λ_k = 2 sin(πk/N)
→ отношения **sin(πk/N)/sin(π/N)** (≤4 различных, все в [1, 2.62]; улей {1, 1, 1.732, 1.732,
2} совпал с [numpy]) — «металлическое семейное сходство» = звук дискретных колец. Веса
(диагональ w) **[numpy]**, 14 форм: при w=1/√2 различимых отношений в объединении 12 → **28**,
совпадений 6 → 4; блок → [1, 1, 1.082] (первое биение, ≈137 центов), улей → [1, 1.109, 1.732,
1.957, 2.144] (вырождения сняты), пруд → щель 1.712 / 2.036 (димеризация орто/диаг), S4 ≠ T4,
ломаная ≠ прямая; тьюб/блинкер не меняются; `shape` оживает только у улья/буханки/корабля
(блок/тьюб/пруд регулярны и во взвешенном смысле). **Но** средняя попарная дистанция 0.369 →
0.351 не растёт, а на библиотеке (A.6-10е) опознание 54 % → 52 %, между/внутри 1.32 → 1.33 —
**идентичности осцилляторов веса не добавляют**.
**Итог.** Ручка `aniso` (дефолт 1 = бит-в-бит; «близко») полезна только как «что нарисовал —
то и слышу» для рисуемых линий/тетромино; как расширитель палитры и как ответ на узость —
снята. Взвешенные длины остаются важными для двери W (A.1 §7), не для спектра.

### B2. Голос и походка осциллятора: идентичность живёт во времени
_(новое; прямое следствие A.6-10)_

**Суть.** У библиотечного осциллятора есть уникальный **голос** — цикл-средний спектр
(прототипы различимы 17/18), — но его закрывает **походка**: разброс фаз (0.288 окт внутри vs
0.380 между) и скачки на тике (медиана 0.306 окт > 0.255 между прототипами). Машина узнаёт
объект по одной фазе в 54 %, по среднему — в 19 %; надёжно различают только период и
последовательность аккордов, а их ухо должно *интегрировать* 2–15 поколений. Это «бипы»
2026-06-15 в числах и главный звуковой факт основного сценария: осциллятор без всякой правки
меняет спектр сильнее, чем отличается от соседа по тулбару.

**Развилка дизайна (решает слух, B7):**
- **(а) голос + походка раздельно.** Стабильный тембр = цикл-среднее; отклонения фаз —
  модуляция с ручкой глубины `gait` ∈ [0,1] (0 = чистый голос, 1 = как сейчас). Нужна память
  по объекту сквозь поколения → **первый настоящий довод построить трекинг идентичности**
  (known issue). Дешёвый суррогат — **идентичность по происхождению**: паттерн, брошенный из
  тулбара, несёт тег; компоненты в его bbox+поле наследуют тег и агрегируются в одно существо
  (Pulsar = 9 компонент = один голос, Traffic light = 4 блинкера = один); скользящее среднее
  спектра по тегу за P поколений (P из библиотеки или по рекуррентности канонической формы);
  тег теряется при столкновении/правке — существо честно распадается в походку, потом в
  пепел. Причинность и локальность соблюдены по построению.
- **(б) походка как музыка.** Не гасить, а сделать событием: скачок фазы на тике =
  ритмический акцент/транзиент (ветка ДИНАМИКА, B9), а не спектральный «бип». Требует
  мс-масштаба.
- **(в) обязательный ремонт независимо от (а)/(б):** при shape>0 якорь f0 глохнет у 46 %
  голосов — под основной сценарий это дефект, не «допустимый нуль» (2026-06-18): пол
  громкости фундаментала (отложенный рычаг) или пул энергии якорной пары; фолбэк «shape
  инертен» (21 %) — туда же.

**Опора.** Спектральный поток — одна из главных осей тембра (McAdams et al. 1995 [Р]) —
походка и есть спектральный поток; «средний спектр + модуляция» — стандартная модель тембра
[Р]; интеграция ритма ухом — [Р, общая]. Остальное — [П]/гипотеза.
**МП (уши, ~30 мин; подготовка офлайн через replay):** 8 библиотечных осцилляторов; задача 1
— опознать по одной фазе (клип 1.5 с, поле заморожено, 2 фазы на объект); задача 2 — по
полному циклу (2–3 периода); сравнить с машиной 54 % / 19 %. Затем предпочтение на 3
объектах: A = как сейчас, B = чистый голос (цикл-среднее как статичный спектр), C = голос +
gait 0.5. **СИ:** суррогат по происхождению — «близко/средне» (тег в `analyse()`, EMA по тегу
в пуле); настоящий трекинг — «средне», общая инфраструктура с ranking СРЕДНЕ №3–5.
**Меняет решение:** узнаёт по циклу, не по фазе, хочет стабильный голос → (а) с трекингом;
предпочитает походку → (б) через B9; не узнаёт ни так, ни так → идентичность библиотеки надо
искать в периоде (темп/ритм-слой), не в спектре.
**Риск.** Цикл-среднее может звучать как размытый металл без характера; у многокомпонентных
осцилляторов «голос» — аккорд колец (М2), усреднение может стереть их различия.

### B3. Стеклов-спектр: слушать границу без трассировки контура (дверь A из того же графа)
_(новое)_

**Суть.** Клетки объекта → граница B (есть мёртвый 8-сосед) и внутренность I; оператор
Дирихле-к-Нейману — шуровское дополнение S = L_BB − L_BI L_II⁻¹ L_IB. Для единичного диска
Стеклов-спектр **0, 1, 1, 2, 2, …, k, k, …** (r^k sin kφ, r^k cos kφ); для гладкой односвязной
плоской области с периметром ℓ: σ_{2j} = σ_{2j−1} + O(j^{−∞}) = 2πj/ℓ + O(j^{−∞}) (Girouard &
Polterovich 2017, теорема 2.1.2: Rozenblum 1979; Edward 1993; Guillemin–Melrose) — **и явно
не выполняется для многоугольников** (§3: у квадрата кластеры по 4 около нечётных кратных
π/2) [веб-проверено]. σ имеет размерность 1/длина → частота ∝ σ. Это дверь A карты 2026-06-22
без трассировки, с дырами и нитями бесплатно. Дискретный Стеклов на подграфах Z² — постановка
изучена (Han & Hua 2019: оценки собственных значений, явных спектров нет [веб-проверено]);
«Steklov/boundary-spectrum sonification» — не найдено [веб-проверено, ограниченно].

**МП выполнена [numpy]** (8-связный L; граница = есть мёртвый 8-сосед). Диск r≤7 (|B|=52,
|I|=97): σ_k/σ_1 = [1, 1, 2.02, 2.16, 3.22, 3.22, 4.13, 4.58, 5.32, 5.32, 5.72, 9.01] —
**пары в пределах ~8 % от целых до k≈10** (√λ того же диска: [1, 1, 1.61, 1.63, 2.09, …] —
не гармонично); при w=1/√2 то же ±1 %. Квадрат 7×7: [1, 1, 1.50, 3.33, 3.44, 3.46, 3.46,
5.31, 5.46, 5.46, 5.67, 6.71] — **кластеры по 4**, ровно картина Girouard–Polterovich для
многоугольников; блок 16×16 аналогично. Итог: круглый толстый блоб → почти-гармонические пары
(биения при асимметрии), прямоугольный → «кластерный» ряд по 4 — два характерных ряда,
различимых на бумаге; в Life нарисованное толстое чаще прямоугольное — т.е. чаще второй.
Драматургия под Life сохраняется: толстое → Стеклов-ряд, автомат выедает в кольца → металл.

**Открытый вопрос (решить до ушей).** При I=∅ S=L, и частота ∝ σ даёт отношения **λ, а не
√λ** (пруд: [1, 1, 3.41, 3.41, 5.83, 5.83, 6.83] вместо [1, 1, 1.85, …]) — «плавная деградация
к текущему движку» **неверна**: на тонких объектах Стеклов-движок вдвое шире в лог-шкале.
Варианты: (а) частота ∝ √σ — деградация плавная, но диск даёт √(1,1,2,2,3,3) — гармоничность
теряется; (б) частота ∝ σ с явным переключением по толщине |I|/|B|; (в) отдельный движок без
претензии на преемственность. Склоняюсь к (в): «вторая читалка той же формы» с иным характером.
**СИ:** `map_steklov` в реестре — «близко». **Меняет решение:** Пользователь на слух различает
круглое/прямоугольное толстое → играбельность через рисование доказана; нет → краска для t=0.
**Риск.** Толстых форм ни в библиотеке, ни в пепле нет (блок 2×2 — весь граница): инструмент
для «рисуем» и для t=0 после вмешательства.

### B4. Захват частот и языки Арнольда: фузия как физика, `harm` как эмерджентность
_(развитие horizons §3 и D/N — с аналитичной теорией вместо Дуффинга)_

**Суть.** Моды объекта — фазовые осцилляторы с частотами √λ_k и слабой связью K через
структуру формы. Курамото даёт унисон (скучно); связь через целочисленные резонансы
(K·sin(qθ_j − pθ_i)) даёт **захват в отношениях p:q — языки Арнольда** [Р]: у краёв языка —
биения и хор (то, что [С] любит в `harm`<1), внутри — целые отношения, порог K_c — играемая
ручка «один голос ↔ аккорд мод», с гистерезисом (память). Это `harm` как процесс, дверь D без
хаоса Дуффинга: фазовые уравнения ограничены, локальны (скачок только на границе языка — и
это слышимое событие). Языки Арнольда экспериментально показаны у связанных органных труб
(«The Arnold-tongue of coupled acoustic oscillators», arXiv:1311.5797 [веб-проверено]) —
фузия как физика реальных инструментов. **Ниша не пуста**: Kuramoto-синт «Kurare» существует
[веб-проверено]; «Курамото на графе формы КА» не найдено — новизна скромная, честно.
**МП (офлайн + 6 клипов, ~1 день):** 8 осцилляторов с частотами пруда, связь по кольцу, K
свип 0→K_c→2K_c; контроль — `harm=1` на том же объекте. **СИ:** аудио-rate интегратор фаз —
«средне».
**Меняет решение:** «harm с жизнью» → N-семейство с гарантиями; неотличимо от harm → снимаем.
**Риск.** [С] «FM даёт тонну разного» — про FM, не про захват; богатство здесь в поведении.

### B5. Life как резервуар: «память вмешательства» как измеримая величина
_(новое как рамка; horizons §9 как практика)_

**Суть.** Reservoir computing на КА (Yilmaz 2014; Nichele & Molund 2017; Nichele & Gundersen
2017 [веб-проверено]; ReCA × звук — не найдено) даёт рамку для «играем через поле»: правка =
вход, поле = резервуар, звук = readout. Ключевое свойство — **fading memory**; у Life (класс 4)
его нет в общем случае — глайдер уносит информацию навсегда (в супе тор не успокаивается,
A.6-7; в сценарии — обломки и корабли после разрушения) —
это одновременно причина «глубокой игрушки» и непредсказуемости. Величина: **T_mem(правка)** =
поколения, за которые звуковая дистанция «с правкой vs без» падает ниже порога — *временная*
локальность.
**МП (офлайн, полдня):** 30 объектов × 5 правок × 200 поколений; распределение T_mem по
классам. **СИ:** ноль — метрика.
**Меняет решение:** T_mem бимодально (0 или ∞) → «играть через поле» = играть событиями, а не
состояниями; ветка ДИНАМИКА выше статики.

### B6. Липшиц-аудит и empowerment: локальность и играбельность как числа
_(новое; методология; первая половина уже выполнена — A.6-6)_

**Суть.** Локальность: распределение d_звук/d_поле по одноклеточным флипам; хвост = каталог
разрывов: порог децимации 256, пересортировка голосов по размеру (`objs.sort`), смена числа
мод, слом симметрии (законный), якорь f0 (A.6-5/10д), базис вырожденных мод (A.6-3) и
главный — внутрицикловые скачки без всякой правки (A.6-10г). Референс —
**damage spreading самого автомата** (Bagnoli, Rechtman, Ruffo 1992 [веб-проверено]; для 2D
— Baetens & Gravner, Lyapunov profiles [веб-проверено]): у Life скорость света 1 клетка/пок;
маппинг не должен быть *менее* локален, чем Life. Играбельность: **empowerment** (Klyubin,
Polani, Nehaniv 2005; Salge, Glackin, Polani 2014 [веб-проверено]) = пропускная способность
канала «n правок → звук через k поколений», Монте-Карло на 8 кистей × 8 позиций.
**МП:** аудит флипов сделан по частотам (A.6-6) и по амплитудам при shape=1 (A.6-9);
следующее — временны́е признаки и empowerment (1 день). **СИ:** ноль.
**Меняет решение:** это *инструмент* для всех ставок; конкретно уже показал (§C.3), что
масштабная зона «правильной» чувствительности отсутствует — и это довод за readout с
пространственным разрешением (B9), а не за подкрутку спектра.

### B7. Опознание и сходство руками: MDS Пользователя на библиотеке
_(замена GW; методология; ушная половина B2)_

Материал — библиотечные осцилляторы, не пепел. **Задача 1 (опознание):** по одной фазе и по
полному циклу (B2-МП) против машинных базовых линий 54 % / 19 %. **Задача 2 (сходство):**
8 осцилляторов → 28 пар, клипы по полному циклу, «насколько похоже звучит» 1–7; отдельно
«похоже выглядит». Мантель + MDS звуковой матрицы = размерность палитры библиотеки *в ушах* и
калибровка EMD-метрики A.6-10 по человеку; повторить после ремонта якоря (B2в).
**Опора.** Психофизика тембра (Grey 1977; McAdams et al. 1995). **МП = прослушивание** (через
record/replay; ≈30 мин). **СИ:** ноль.

### B8. Экран — половина инструмента: рендер поля как свободная переменная маппинга
_(новое как направление; Шутц–Липскомб как ресурс)_

Зрение редактирует слух [Р]; Пользователь играет с экраном → визуал — законный канал,
бесплатный по звуку: яркость по возрасту (возраст — в глаза, раз не в частоты: B-снято), шлейфы
рождений/смертей (то, что `dyn` не дал ушам), раскраска по доминирующей моде. Looming (Neuhoff
1998; Maier et al. 2004; Ghazanfar & Maier 2009 — восходящая частота слышится как приближение
[веб-проверено]): скорость глайдера известна (c/4) → «время до столкновения» вычислимо →
нарастание громкости/высоты *до* удара — предвестник для `acc`. Гипотеза [П]: предвестник
делает столкновение играемым. **МП:** 4 клипа glider-vs-block (± шлейф, ± предвестник) +
экран. **СИ:** UI — зона Developer.

### B9. Один эксперимент для всей ветки ДИНАМИКА: «мс-масштаб из формы»
_(следствие A.4-а и §C.3; различающий эксперимент)_

Мс-структуру даёт только промежуточная система → вопрос ветки один: **зависит ли её транзиент
от формы?** Матрица: событие (глайдер бьёт в объект) × объект ∈ {блок, улей} × система ∈ {(0)
статичная сумма + `acc` — контроль; (1) E+ scan с правками A.4 (фиксированные координаты
чтения, память ± событие); (2) N0 Codex (с оговоркой о 6 числах); (3) B4 захват-лайт}; для
каждой — «замороженная форма». ~10 клипов × 300 мс после удара. Критерий: Пользователь
различает блок/улей *по транзиенту* хотя бы в одной системе. **Ни в одной** → «форма →
мс-масштаб» ложна, динамику делаем формонезависимой (acc-подобной), N/S/W сужаем разом.
**В одной** → она движок ветки. Дополнительный довод из §C.3: только системы с точечным
возбуждением (волна из клетки) дают отклик O(1) на один флип независимо от N — то, чего спектру
не хватает по построению. И второй, из A.6-10г: походка осциллятора — скачок спектра на тике
(медиана 0.3 окт) — это событие; без мс-масштаба оно остаётся «бипом», с ним может стать
ритмом (B2б). Объекты для матрицы — библиотечные: Beacon (скачок 1.04 окт) и Tumbler
(узнаётся 14/14).

### B-снято по итогам МП [numpy] — возрастные веса рёбер
_(ranking №2 наоборот: возраст в частоты)_

Идея: w_ij = g(min(age_i, age_j)) — новорождённая клетка входит «мягкой», спектр непрерывен по
Вейлю, ротор/статор (LifeWiki: rotor — клетки, меняющие состояние за период; stator — всегда
живые; volatility = |rotor|/(|rotor|+|stator|) [веб-проверено]) расходятся сами; крукс — якорь
f0 (argmin разрывен). **МП:** осцилляторы целиком, старт из зрелого состояния, 40 пок,
τ∈{2,5}, w_min∈{0.2,0.5}; max |Δlog₂ якоря| без весов → с весами: блинкер 0.000 → 0.26–0.48;
жаба 0.262 → 0.52–0.74; маяк 1.54 → 1.8–2.0; пульсар 0.95 → 0.82–0.85 (доля <1 полутона 0.33 →
0.00); пентадекатлон 1.663 → 1.663; Figure-8 1.94 → 2.2–2.4; модуляция мод 2–6 за поколение
0.37–0.50 → 0.37–0.53; gated-якорь хуже argmin. **Вывод:** нестабильность доминируется
дискретной сменой множества узлов по фазам (= A.6-10г), не жёсткостью рёбер; пересмотр «не
глайдить» снят. Гипотеза «призраки» (фиксированное множество узлов, мёртвые клетки с массой
ε, Lφ = λMφ) — не проверена, низкий приоритет; возраст — только в глаза (B8).

### B-отвергнуто (проверено выкладкой, не строим)

**Магнитный Лапласиан** (Fanuel, Alaíz, Suykens 2017 [веб-проверено]): L_g = D − T∘A с фазами
e^{igθ}. Зеркальный корабль = обращение рёбер = L_{−g} = conj(L_g) → **тот же спектр**;
хиральность живёт в собственных векторах — амплитудный канал, слаб [С] и вреден на библиотеке
(A.6-10д). **Реверб-тор/амбисоника**, **NCA×DDSP**, **метапиксель** — вне спины и пропускной
способности.

## C. Сквозная теория: почему палитра узка, и как спина становится числами

### C.1 Четыре механизма узости — с измерениями на библиотеке

**М1. Идентичность осциллятора живёт во времени, а не в спектре.** [numpy A.6-10] Цикл-средний
голос уникален (17/18 прототипов различимы), но фазовый разброс (внутри 0.288 vs между 0.380)
и скачки на тике (медиана 0.306 > 0.255 между прототипами) его закрывают; по одной фазе машина
узнаёт объект в 54 %, по среднему — в 19 %. Надёжно различают только период и
последовательность аккордов — «походка», которую ухо должно интегрировать 2–15 поколений.
«Библиотека звучит одинаково» = все осцилляторы звучат одним дрожащим металлом, потому что их
дрожь больше их различий. Пепел (A.6-7) — конец жизни: разрушенный осциллятор распадается в
аккорд блинкер/блок/улей + обломки; это звук смерти, не сцена.

**М2. Спектральная тривиальность компонент.** Фазы-компоненты осцилляторов — часто кольца,
линии, клики (Pulsar — 9.3 компонент на фазу; Traffic light = 4 блинкера = спектр одного
блинкера, EMD 0): отношения sin(πk/N)/sin(π/N), ≤4 различных в [1, 2.62]; схлопывания через
изоморфизм (P4 ×3, S=T), не коспектральность (0 пар). Сегментация «объект = связная
компонента» дробит библиотечное существо на голоса-кольца — довод за идентичность по
происхождению (B2а).

**М3. Потолок яркости от якоря f0.** λ ≤ 2·deg_max = 16 (кольца ≤ 4) → максимальное отношение
4/√λ₂; [numpy]: верхняя мода/f0 от 1.0 (блок) до 8.16 (Figure-8); выброшенный √λ₂ разбросан
×6.3; `spread` выбирает из того, что есть. Поправка к «Вейль → плотность растёт к верху»
(decisions 2026-06-17): у ограниченного дискретного оператора верх — 4·f0/√λ₂. Выходы: другой
оператор (B3, толстые), ослабление якоря — регистр по размеру (load-bearing развилка
2026-06-16; Adeli: «большой = низкий» перцептивно слаб, но для инструмента это дизайн-выбор —
называю, не открываю), промежуточная система (B9).

**М4. Амплитудный канал слаб [С] и на библиотеке вреден [numpy].** shape=1: опознание не
растёт (19 %), скачки удваиваются (0.591), **якорь глохнет у 46 % голосов**, инертен у 21 %,
на вырожденных модах не инвариантен к повороту (×4). Пул энергии чинит поворот (T-тетромино →
[0, 1, 1]) — обязателен; пол громкости фундаментала (отложен 2026-06-18) — обязателен под
сценарий (B2в). Интерпретация: `shape` «различает формы» на слух [С] через слом симметрии
(нули рождаются/исчезают на 3.7 окт за флип), т.е. через походку, а не через голос.

**Конкурирующие объяснения** (Codex R0): (К1) потери в нормировках/отборе — абляция n и
нормировок; М1/М2 предсказывают узость даже при полном спектре; (К2) статичный рендер — B9;
(К3) ухо: roughness маскирует — B7 при harm=0 vs 1.

### C.2 Ведомость потерь «форма → звук»

Намеренные (инвариантности = играбельность): позиция, поворот, отражение — **поворот при
shape>0 нарушен (A.6-3)**. Случайные, ставшие структурными: **геометрия сверх графа** (P4 ×3;
B1), **абсолютный масштаб λ₂** (якорь; Fiedler 1973 [Р]; по Чигеру ≈ близость к расколу —
предвестник split-события, выброшенный нормировкой; кандидат оси «натяжение» с нормировкой на
размер, иначе это просто размер), **собственные векторы** (канал, вредный на библиотеке — М4), **всё
сверх n мод**, **фазы**, **время** (мс-масштаба нет — B9), **1–2-клеточные объекты** (16 %
голосов: тишина/чистый f0). У каждого пункта — либо дверь в B, либо осознанный отказ.

### C.3 Локальность и играбельность как величины — что показал аудит

**Правка в основном сценарии — намеренное разрушение.** Пользователь ломает осциллятор; Life
сам гиперчувствителен к флипу (damage spreading, B6: блинкер + клетка = не блинкер). Значит
гиперчувствительность мелких форм к флипу (A.6-6: медиана 0.176 окт, каждый флип меняет число
мод; при shape=1 амплитуды — 3.7 окт) **сама по себе не дефект** — она согласована с
автоматом. Критерий переформулирован: **звук должен меняться настолько, насколько меняется
Life** — L_edit = d_звук(правка)/d_Life(правка) ≈ const по масштабам (у кляксы 233 клеток
флип не меняет ни Life, ни звук — 0.009 окт — тоже согласовано). В относительных единицах
карта уже почти равномерна (0.176·6 ≈ 1.1 у мелких vs 0.009·233 ≈ 2.1 у кляксы; низшие моды
делокализованы, |φ(i)|² ~ 1/N → δλ/λ ~ 1/N).

**Главный нарушитель — не правка, а цикл.** Скачки спектра между фазами осциллятора *без
всякой правки* (A.6-10г: медиана 0.306 окт, p90 0.845) больше расстояния между разными
объектами (0.255). Вторая величина: **L_cycle** = d_звук(соседние фазы)/d_между(прототипы) —
сейчас ≈1.2, цель <0.3 (B2а) или превращение скачка в событие (B2б/B9). Из теории: спектральное
чтение даёт отклик O(1/N) на точечное изменение, readout'ы с пространственным разрешением —
O(1) (волна из клетки, E+/S1; граница, B3; события, acc) — довод за B9 для ветки (б).

- **Локальность (пространственная):** L_edit по флипам библиотеки и L_cycle по фазам; хвост
  только на законных разрывах (слом симметрии, раскол), не на артефактах (децимация,
  сортировка, якорь, базис).
- **Локальность (временная):** T_mem (B5) — сколько поколений после правки осциллятор «помнит»
  себя до распада.
- **Причинность:** доля дисперсии звуковых признаков, объяснённая полем при фиксированных
  ручках (контроль «замороженное поле» — везде).
- **Играбельность:** опознание осциллятора ухом по фазе/циклу против машины 54 %/19 % (B7);
  empowerment (B6); предсказуемость «выглядит ↔ звучит» — мера предвидения, не bouba/kiki.
- **Богатство:** размерность MDS звуковой матрицы Пользователя на библиотеке (B7), до/после
  двери; машинная база — 56 различимых из 91 фазовых спектров, 18 различимых голосов.

## D. Шорт-лист (2–3 ставки под реальную пропускную способность)

Офлайн-часть считают Developer/оркестратор, Пользователь смотрит на числа; уши — по одному
короткому сеансу на ставку (≈30 мин + ~10 клипов + 4 клипа).

1. **Голос против походки (B2) + ремонт якоря (B2в).** МП по числам сделана [numpy A.6-10].
   Дальше: (i) слуховой тест опознания по фазе/циклу (B7, ~30 мин) против машины 54 % / 19 %;
   (ii) предпочтение «как сейчас / чистый голос / голос + gait» на 3 объектах; (iii) REQ на
   ремонт: пол громкости фундаментала при shape>0 + пул энергии вырожденных мод (дефолты
   бит-в-бит) — нужен при любом исходе. Итог решает развилку «среднее + отклонение с
   трекингом по происхождению» vs «походка как ритм» (→ ставка 2). `aniso` (B1) —
   вспомогательное, в тот же REQ как ручка с дефолтом 1.

2. **«Мс-масштаб из формы» (B9).** Один сеанс ~10 клипов закрывает или открывает N/S/W разом;
   довод из A.6-10г: походка — событие на тике, без мс-масштаба она остаётся «бипом». Стенды —
   офлайн-скрипты поверх `casynth_core`; объекты — Beacon и Tumbler из библиотеки.

3. **Стеклов (B3).** Развилка «σ / √σ / отдельный движок» решается на бумаге, затем 4 клипа:
   круглый и прямоугольный толстый блоб × Стеклов/Лаплас. Ставка на играбельность через
   рисование (вмешательство Пользователя — часть сценария).

Снято по итогам МП: возрастные веса (B-снято). Названо, не сейчас: B4 захват (если B9 выберет
N-семейство), B5/B8 (в VST-контексте визуал и память правки ключевые). VST-развилка ни одной
ставкой не блокируется.
