## Что сделано

1. **Геометрия фигур** `casynth_lab/figures.py`: компоненты 8-связности **через шов тора**
   (`ndimage.label` + объединение меток по краям, включая диагонали); периодический центр — точный
   минимизатор суммы квадратов кратчайших расстояний по каждой оси (перебор всех n «разрезов»,
   F вычисляется точно; разрывы F — только локальные максимумы, поэтому минимум всегда среднее одного
   из разворачиваний), равные минимумы (в 1e−9) — ближайший к прежнему центру, для новой фигуры —
   наименьшая координата; `R = max` торового расстояния до клетки; маски Disk (граница включена,
   +1e−9) / Own; спектр: `L = D − A` полного невзвешенного графа 8-соседей по модулю тора, `eigvalsh`,
   нулевая мода отброшена, до 24 наименьших положительных с кратностями, √λ. **Матрица строится
   из канонического размещения** (круговые смещения от первой клетки, сдвиг в (0,0)) — одна форма
   в любом месте/через шов даёт побитово те же собственные значения; кэш по тому же ключу.
   Сопоставление `match()`: граф перекрытий старые×новые; компонента графа «1 старая ↔ 1 новая» —
   продолжение, любая другая (распад/слияние/цепочка) — все старые в хвосты, все новые — новые id;
   оставшиеся без перекрытия — по смещению центров ≤ 1.5 клетки (ближайшие, детерминированные
   тай-брейки). Центр компоненты для смещения считается один раз (не на пару).
2. **Движок** `casynth_lab/object_resonators.py` (`ca_object_resonators`, кнопка «Objects»,
   `model_version=ca_object_resonators_n4_v1`, `STATE_VERSION=1`). Граница блока только при
   изменении поля относительно последнего отрендеренного: трекинг → для продолжающейся фигуры
   `e = Σ births·K_cur + Σ deaths·K_prev` (K_prev — маска прежней геометрии в ТЕКУЩЕМ режиме),
   для новой — `Σ births·K_cur`; `a = e/(e+2)` в оба импульсных состояния слота (форма импульса N2:
   0.25/2 мс, сила 0.75, константы из `event_network.consts`). Перестройка: мода j → мода j (по
   возрастанию), новые моды с нуля, исчезнувшие звучат без входа на старых частотах и с прежним
   весом, веса 1/n продолжающихся мод — рампа 882 отсчёта; панорама `cos/sin(π·p/2)`,
   `p = cx/(cols−1)` — рампа 882; decay r и gain стенда — рампы 882 на семпл-пути (gain = линейная
   рампа к цели, а не блочный косинус N2/N3). Ядро numba: слоты 24 активных + 96 хвостов + 24
   затухающих (единый пул 144 с ролями), пропуск свободных слотов и мод выше `n_live`
   (побитово эквивалентно), HP 20 Гц на канал, `out = hp·0.5·gain[k]`. Освобождение хвоста при
   всех |z| < 1e−7 на границе блока; при переполнении хвостов самый тихий уходит в затухающий
   слот (веса → 0 за 20 мс), при переполнении и его — самый тихий затухающий обнуляется сразу и
   считается (`dropped`, виден в панели). Недоведённые моды < 1e−7 обнуляются на границе блока
   (детерминированно). Фигура без свободного слота отслеживается (id/цвет/центр), звучит когда слот
   освободится — «звучат X из Y». Одиночная клетка: R=0, центр виден, слота не получает.
   Ручки: `detector` Own/Disk (только маски следующих событий), `frequency_scale` 55…880
   (перестройка всех занятых слотов, состояния сохранены), `decay_s` 0.20…1.50. Снапшот: все
   массивы слотов + трекер (`fig_ids/slots/centres/radii/cells/offsets`, `next_id`) + оба поля +
   рампы + HP + gain + счётчики; restore сверяет фигуры с компонентами `grid_prev`, спектры с
   пересчётом (rtol 1e−9), `ffreq == scale·sqrtlam` точно, роли/слоты; cos/sin пересчитываются
   `math.cos/sin` (побитово на той же машине). Хуки: `raw_block`, `inject(slot, a)`.
   `display()`: список фигур (id, color=(id−1)%12, slot, n, cells, centre, radius, modes, f_low,
   e, a, level) + счётчики + режим/параметры — источник геометрии для UI.
3. **Стенд** `demo_bench.py`: `_draw_figures(disp)` рисует фигуры ПРОСЛУШИВАЕМОЙ стороны из

## Измерения (gain 0.028)

- N4.1 glider: Б (N4 Disk) −40.11 dBFS, пик 0.0561 (preflight −40.10 / 0.0561); А (N3 Tuned) −42.36 dBFS,
  пик 0.041 → А тише Б на 2.25 dB; параметра сцены на одну сторону нет, ×0.5 оставлен (вопрос).
- N4.2: Own −35.56 / Disk −35.20 dBFS (preflight −35.54 / −35.18), пики 0.0817 / 0.0855; Disk−Own
  относительно Own −11.06 dB при разнице общего RMS +0.35 dB (preflight ≈ −11 / 0.36) — добавочный
  отклик, не подъём уровня. Приёмник: Own e=0, Disk e=4 каждое поколение; при переносе блинкера за
  круг — 0. У glider один id на весь круг, ровно два чередующихся спектра.
- Тайминг обеих сторон после прогрева: p99 ≈ 1.0 (N4.1) / 1.5 (N4.2) ms при бюджете 7.98.
- Анализ фигуры (eigvalsh) на render-потоке при каждом изменении поля: 64 клетки 0.4 ms, 121 — 1.3,
  256 — 7, 529 — 37, 1024 — 101 ms → фигуры > ~300 клеток превышают бюджет блока сами по себе
  (офлайн точно, живой стенд может дать underrun); в сценах ≤ 17 клеток.
- Стресс при gain 0.04: конечно везде; клип до PCM в плотных/случайных пробах при scale 55 / decay 0.2
  и «ручки в движении»; hard drops только при замене всего поля каждый блок; всё в отчёте как
  ограничения стресс-проб, сцены чистые (пики ≤ 0.09).
- Все записи каталога воспроизводятся точно (`Catalog.replay` match), Continue побитово.

## Решения Developer (вне ТЗ, детерминированы и в версии модели)

- Распад/слияние — по компонентам графа перекрытий (ТЗ: «старые участники в хвосты, новые компоненты
  — новые банки»); продолжение без перекрытия — смещение центра ≤ 1.5 клетки.
- Исчезнувшие моды сохраняют прежний вес (без рампы), новые получают 1/n с рампой; при повторном
  «оживлении» моды j её состояние не обнуляется (без щелчка).
- `frequency_scale` перестраивает и хвосты (ручка пользователя действует на всё звучащее).
- Освобождение хвоста/обнуление тихих мод по порогу 1e−7 амплитуды — на границах блоков.
- Пул затухающих 24 сверх 24+96; hard drop — последний рубеж, всегда посчитан и показан.
- Спектр из канонического размещения (иначе кэш давал расхождения 1e−14 между непрерывным прогоном и
  Continue — найдено тестом Continue).

## Дополнение 2026-09-16 (вечер): ручка «Radius x» (запрос Пользователя)

`radius_mul` 0.25…4.0, дефолт 1.0 (бит-в-бит). Только Disk: `R_eff = radius_mul·R` для маски
событий, панели и круга на экране; геометрический R фигуры не меняется (в `display()` —
`radius` = эффективный, `radius_geom` = геометрический); одиночная клетка остаётся R=0; Own
игнорирует; смена ручки — не удар (действует на маски следующих событий, как переключатель
Own/Disk). Старые снапшоты без параметра восстанавливаются с 1.0 (`OPTIONAL_PARAMS`), модель
не переименована. Каталог пересобран (записи `20260916-213632-002902` N4.2 и
