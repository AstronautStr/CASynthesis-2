## What was built
- **`casynth_lab/provenance.py`** — execution provenance (schema 1). Explicit runtime
  set (no import analysis): `demo_bench.py`, `casynth_lab/*.py`, `casynth_core.py`,
  `casynth_engine.py`, `casynth_config.py`, `requirements.txt`, `demos/*.json`. Per-file
  sha256 of LF-normalised bytes (CRLF checkouts equal the LF blobs) + one digest;
  repo id (root commit), full HEAD commit, `match` clean/dirty/unknown computed by
  comparing the WORKING content of the set with the commit's blobs (`git cat-file
  --batch`, staged/unstaged/new runtime files all count, docs/tests/memory don't);
  environment separately (Python, exact numpy/scipy/pygame/sounddevice versions, OS,
  machine, audio ctx). `current()` captures ONCE per process at first use — the
  imported code, never the HEAD at Save time; `loaded_from` verifies the imported
  casynth modules live under that root (else match = unknown). Pin refs
  `refs/casynth/pins/<commit>` (`hold_commit`, verified after `update-ref`).
- **Runner / recorder / catalog**: `DemoRunner(provenance=...)` (default = process
  provenance), cut carries it, record format **3** (1/2 still read): `provenance`,
  `status` pinned|local, `status_reason`, `pin{commit, ref}`. Save pins only when
  match == clean AND the ref was created (ref first; any failure → local with the
  reason, never a false pin). `Record.status` is pinned only with a consistent
  provenance + pin block (a garbage/absent block reads as local: "code version not
  recorded"). `Catalog(root, repo_root)`; `repo_root=None` never pins (tests).
  `pin(rid)`: finds the commit whose runtime digest equals the record's (HEAD, then
  `rev-list -n200`), or checks an explicit commit; only provenance/status/pin fields are
  rewritten (atomic tmp + replace); mismatching code (even identical PCM) is refused.
  `source_plan(rec)`: pinned + same digest here → in-process; pinned other version →
  environment check (same Python major.minor, exact package versions, machine) →
  commit exists → 'worktree'; local → in-process "local / current code".
- **`casynth_lab/versions.py`** — worktree cache `lab_catalog/worktrees/<commit>/`
  (`git worktree add --detach`; verified HEAD == commit and runtime digest == commit's;
  broken → removed + recreated from the held commit; main checkout/index/branch never
  touched). `ChildBench` launch contract: `python demo_bench.py --catalog <abs root>
  --record <id> --action continue|check` run FROM the worktree with PYTHONPATH stripped;
  first stdout line = the child's provenance JSON, last = `status`.
- **`demo_bench.py`**: `--catalog/--record/--action` (+ `--headless --seconds --out`
  for workers/tests: renders from the snapshot into npz and saves the continuation as a
  branch); prints its provenance line at start; catalog UI: list tag `Pinned <sha7>` /
  `Local`, card line `Pinned abc1234` or `Local: <reason>` + source availability,
  **Pin to commit** button on local records, Continue label = "Continue (this version)"
  / "Continue in version <sha7>" / "Continue (local / current code)"; a version child
  runs while this bench sits muted in the catalog screen (other actions say "busy");
  on exit the catalog refreshes and the status names the child's commit.
- Tests `tests/test_demo_lab_s6.py` (6, `check.py` gate 1e), all in isolated repos under

## Notes / limits
- Only revisions ≥ S6 support the launch contract; a record pinned to an older commit
  cannot be continued "in its version" (concrete reason shown; WAV plays).
- "Same version" = same runtime digest (the commit may differ, e.g. a docs-only commit
  after the record) → in-process continue.
- Pinned ≠ reproducible: Check reproducibility is a separate verdict computed with THIS
  code; the child `--action check` computes with the pinned version.
- Environment support = the current interpreter only (exact versions must match).
