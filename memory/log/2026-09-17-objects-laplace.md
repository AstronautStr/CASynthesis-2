## Коммиты

1. `core: laplacian_modes()` — спектральная часть `map_laplacian` вынесена в функцию на готовой матрице L;
   `map_laplacian` строит L и вызывает её. Побайтно прежний путь: 4802 случайных сравнения с прежней
   версией (патчи 2…13 клеток, все 7 настроек, exc, децимация) — 0 расхождений; golden master
   `cd3126907ad13b6c` цел.
2. `bench: copy_spectrum ...` — команда раннера `copy_spectrum src/dst` (только общие ключи
   `registry.spectrum_keys(a, b)` = семь настроек Laplace, у гармонических движков только `n`; без общих —
   отказ с сообщением; движок, Detector, Radius, Decay не трогает, рестарта нет), кнопки «<< spectrum B to A» /
   «spectrum A to B >>» в панели (прежние `<<`/`>>` полной копии сохранены); сцена `audio.side_gain {A, B}`
   (опционально, default 1.0 = старые сцены/записи побайтно; постоянный множитель до клипа в init/switch/render,
   в снимке, Replay/Continue его применяют; валидация (0, 16]); панель растёт под 12 настроек + строки фигур
   (окно 32×32 → 916 px по высоте).
3. `Objects v2` — движок, тесты, сцены (ниже).

## Движок `ca_object_resonators` v2 (`model_version=ca_object_resonators_n4_v2`, `STATE_VERSION=2`)

- **`spectrum` Figure / Laplace** (choices; дефолт реестра Laplace; отсутствие ключа в параметрах/снимке =
  Figure = побитово прежний спектральный путь N4) + семь настроек из `ENGINE_BY_ID['laplacian']['params']`
  (метаданные не дублируются). `inactive()`: в Laplace — `frequency_scale` («Figure law only (f0 = scene)»),
  при `shape=0` — `dyn` («acts only with shape > 0»); в Figure — все семь («Laplace only»).
- **Laplace-закон** `laplace_modes_of(cells, rows, cols, f0, settings, exc)`: каноническое размещение
  компоненты (`figures.canonical_placement` — тот же массив, что `canonical_cells`, плюс порядок узлов);
  `fullshape=1` → `figures.laplacian_matrix` (полный торовый граф, без потолка 256/децимации) →
  `casynth_core.laplacian_modes`; `fullshape=0` → `extract(sub, 8)` канонического bbox → `map_laplacian`
  (окно 8×8 как у старого пути, exc через `_crop_like_extract`). `dyn`: значения `exc` в клетках фигуры в
  порядке узлов графа (только веса, при `shape>0`). Веса = `LAPLACE_GAIN` × амплитуды, банк `Σ w_j Re z_j`.
  Нижняя мода = `ctx.f0`. Слот помнит закон (`smode`), по которому настроен; `frequency_scale` перестраивает
  только Figure-слоты.
- **Равенство со старым Laplace:** на всех компонентах 73 состояний трёх сцен × 3 набора настроек
  (в т.ч. full=0 и dyn с exc) частоты и веса/0.7 совпадают с `map_laplacian` на bbox объекта **побитово (0.0)**;
  1722 компоненты / 8434 моды в отчёте.
- **Перестройка без удара:** смена `spectrum`/семи настроек (`set_params`) и приход нового `exc` на том же
  поле (когда dyn действует: `E_prev` сравнивается на границе блока) → `_retune_all`: частоты сразу,
  состояния сохранены, веса рампа 882; импульсные состояния не трогаются (проверено на всех 12 ручках + Restore).
- **Правила хвостов (P2 ревью):** `_tune_slot(s, freqs, weights, sq, mode, ramp)`: при уменьшении числа
  ведомых мод исчезнувшие уходят через `_split_tail` в отдельный tail-слот (состояния, частоты, веса, рампа,
  панорама скопированы; `ndrive=0`), в активном слоте обнуляются → возвращающаяся мода стартует с нуля,
  старый хвост удара не получает. `_tail_slot()`: свободный tail, иначе самый тихий tail → fading (20 мс,
  `faded`); если и fading заняты → **затухание на месте**: уходящая фигура — `_fade_slot` в своём активном
  слоте (`in place`, слот занят 20 мс, освобождается `_release_quiet`), исчезнувшие моды — веса → 0 в банке.
  Единственный обрыв (`dropped`): такие моды при возврате фигуры в эти 20 мс при всё ещё занятых пулах.
  Стресс 48 блинкеров × 8 циклов: 96 tails, 24 fading, 48 faded, 24 in place, 0 dropped (в v1 — 72 обрыва).
- Снимок: + `smode`, `exc_pending`, `exc_prev`, `laplace_gain`, `f0`; проверки по закону слота (Figure —
  спектр из клеток и `ffreq == scale·√λ`; Laplace — `ndrive ≤ n`, нижняя мода ≈ f0, частоты > 0);
  старые снимки без новых ключей восстанавливаются как Figure (тест). Счётчики: + `inplace_fades`.
- Панель стенда: строка «R x… Laplace f0 110 Hz n 12 full / scale … decay …», «faded / in place / dropped»,
  подпись оверлея `[Disk, Laplace]`, надпись над полем «spectrum Laplace».

## Измерения (`demos/objects_laplace_report.py` → `demos/results/objects_laplace/report.{json,md}`)

- Семь ручек на Galaxy (фазы 0–7): spread / full — [2, 4, 5] (== preflight); alpha / shape / harm — все 8;
  dyn — 1–7 (в фазе 0 событий ещё нет); **`n` — [0,1,2,4,5,6]**: в фазах 3 и 7 все компоненты по 4 клетки
  (3 моды), n=4 и n=12 выбирают те же три — preflight считал дополненный нулями массив (вопрос в `questions.md`).
- L3: приёмник e = 0 на поколение при ×1, 4 при ×1.5, блинкер 4 при обоих (71 поколение), id постоянны;
  рычаг ×1.5→×1 вживую: удара от ручки нет, следующее поколение приёмник 0 / блинкер 4.
- L2: 72 поколения, 315 идентичностей, до 12 фигур / 8 звучащих / 51 хвост, 0 faded/in place/dropped;
  правило 4→2→4 на обоих законах: возвращающиеся моды 0 до первого сэмпла, хвост без входа, id сохранён.
- Continue с 6 с точен (200 блоков) во всех сценах; каталог — все три записи `match`.
- Тайминг обеих сторон после прогрева: p99 2.30 / 5.83 / 3.38 ms (max 3.97 / 7.34 / 6.25) при бюджете 7.98.
- Стресс (gain 0.04, отдельно): finite во всех 8 пробах; клип у Б в 5 пробах (пики до 2.97 при полном
  переключении поля каждый блок с n20/shape1), у А в одной (knobs_moving, 1.10); все 8 проб выше бюджета по p99
  (анализ плотных полей на render-потоке: полный граф без потолка — 256 клеток shape 1 = 11.8 ms, 1024 — 205 ms);
  in place 117/131 при случайном поле каждый блок; hard drops 0.
- Отчёт N4 перегенерирован тем же кодом: пик и клип пробы хвостов — в сводке (P2 №3).

## Дополнение 2: Description и окно Notes (по запросу пользователя)

  одной записи: `sync_notes()` закрывает его, когда `notes_target()` ≠ rid (другая запись, Back,

  каждое изменение. Модуль в `SOUND_EXCLUDE`. Тесты: `test_text_fields_share_one_model` (через
