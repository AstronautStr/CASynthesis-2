# 2026-07-06 — `ab_bench.py` (A/B стенд слухового сравнения)

Реализация по спеке `memory/req-ab-bench.md`. Роль: developer.

## Что сделано
Новый самодостаточный файл `ab_bench.py` — pygame-стенд мгновенного A/B двух
преднастроенных полей на одинаковой захардкоженной сцене. Существующие файлы
проекта НЕ тронуты (только импорт из `casynth_*`/`patterns`).

**Три зоны окна (фикс. размер, геометрия кейса вписывается в вьюпорт подбором
размера клетки):**
- Тулбар: 5 кнопок кейсов. Клик → ОБА поля сброшены на initial, стоп, тишина
  (`active=None`).
- Два поля A/B рядом (одна геометрия из кейса). Клик по полю → рестарт этого
  поля с initial + оно бежит и звучит; другое замирает и молчит. Повторный клик =
  рестарт. Звучит максимум одно поле. Рисования клеток нет. Рамка: выбранное
  (editing) — акцент, звучащее — толстая цветная (A=cyan, B=amber) + «▶ SOUNDING».
- Панель сбоку: редактирует ВЫБРАННОЕ поле (подпись «EDITING FIELD A/B»).
  Per-field: селектор движка (вкладки из `ENGINES`) + динамические крутилки по
  param-спекам реестра + ENV (A/D/S/R, tune). Общие: note (MIDI-слайдер), vol,
  speed (тиков/сек). Дефолты полей = дефолты реестра.

**Кейсы** (имя, gw×gh, размещения из `patterns.py`):
1. `block` 18×14 — контроль, событий нет.
2. `beacon` 18×14 — осциллятор.
3. `r-pentomino` 56×38 — хаос.
4. `glider` 44×32 — глайдер в пустоту.
5. `glider-vs-block` 40×28 — глайдер @(2,2) на блок @(7,7); чистое столкновение
   тик 7–10 (pop 9→11→6→3→0, взаимная аннигиляция → тишина): «подлёт (стабильно)
   → всплеск событий на столкновении → спад». Проверено: ни один кейс не касается
   шва тора ≥40 тиков (сегментация не wrap-aware — шва избегаем).

## Архитектура аудио (переиспользование, НЕ копия движка)
- Один sounddevice callback-стрим + ring buffer + ОДИН рендер-поток (по образцу
  `gol_synth`). Источник — активное поле. `pool.update`/`render_chunk_laplacian`/
  `SlotPool` из `casynth_engine`.
- **Глушение хвостов при переключении/рестарте:** аудио-состояние (pool + phase/
  amp_cur/pan_cur) держится в контейнере `AU`; на switch/restart/case-select
  главный поток ставит `audio_ctl['reset']=True`, рендер-поток пересоздаёт `AU`
  (мгновенная тишина, без звенящих слотов; вся мутация пула — только на рендер-
  потоке → без гонок).
- **КРИТИЧНО — dyn/exc жив:** `step_field` на каждом шаге пишет `f['exc'] =
  events_field(prev, new)`; `analyse_field` прокидывает `exc=` в `analyse`
  (движки без `dyn` его не получают — как в ядре). Главный поток каждый кадр
  делает analyse активного поля и публикует `render_spec` (immutable ref-swap).
- **tune:** `snap_active` зеркалит `gol_synth._snap_note_on` (Пломп–Левельт через
  `casynth_tuning`): на смене ноты снапит несущую активного поля к минимуму
  диссонанса его спектра; voices рескейлятся к `tuned_f0` перед публикацией.

Session-рекордер (`CASYNTH_RECORD`) в стенд НЕ тащился (по спеке).

## Как запустить (для Пользователя)
`python ab_bench.py` → выбрать кейс кнопкой сверху → **клик по полю A или B**
запускает его звук (другое молчит), повторный клик = рестарт. Панель справа
правит ВЫБРАННОЕ (последнее кликнутое) поле — движок, крутилки, ENV, note/vol/
speed. Для А/Б ручки `dyn` (главная задача стенда): выбери Laplace, подними
`shape` (>0, иначе dyn не действует) на ОБОИХ полях, на A поставь `dyn=0`, на B
`dyn=1`, затем кликай по очереди A и B на кейсах `glider-vs-block` (транзиент
коллизии) и `r-pentomino` (хаос) — это непрослушанные козыри dyn.

## Доп. правка (по просьбе Пользователя): спектр-полоски под A и B
Причина: на симметричных кейсах разница dyn=0/1 может быть неслышима (см. ниже),
но ВИДНА в спектре. Под каждым полем (внизу вьюпорта, `SPEC_H=62`) рисуется
read-only спектр СВОЕГО поля через переиспособленную `casynth_ui._draw_spectrum`
(лог-ось 20..20000 Гц, столбики мод по объекту, маркер несущей). `field_spectrum`
кэширует analyse по сигнатуре (id(grid), gen, engine, f0, params) → замороженное
поле не пересчитывается, правка ручки/шаг обновляют; активное поле берёт voices
из того же кэша (один analyse/кадр). `_draw_spectrum` импортируется лениво в
main() (selftest остаётся headless). selftest PASS, headless smoke + скриншот
подтверждают отрисовку обеих полос.

**Панорама отключена (по просьбе Пользователя):** публикуемые в аудио voices
форсятся `pan=0.5` (центр) → позиция объекта по X не окрашивает A/B-сравнение
тембра. Проверено: max|L−R|=0 (моно-центр). Спектр/движок/`analyse` не тронуты.

**Диагностика «нет разницы A/B» (Пользователь слушал beacon):** проверено сквозь
весь пайплайн — не баг. Аудио-буфер max|Δ| dyn0 vs dyn1: r-pentomino=4503,
glider=3122 (слышно), **beacon=0, block=0**. На beacon события есть (exc=4.2), но
объекты — симметричные 3-клеточные фигуры → проекция возбуждения на собств.
векторы сокращается (тот же `Σ⟨e,φ⟩=0`, что на blinker) → dyn инертен. То есть
2 из 5 кейсов (block намеренно + beacon по симметрии) — dyn-контроль. dyn слышно/
видно на r-pentomino (хаос) и glider/glider-vs-block (асимметрия/коллизия).
