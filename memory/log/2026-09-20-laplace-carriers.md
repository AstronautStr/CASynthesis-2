# 2026-09-20 — Laplace carriers: фильтр несущей и банк волн на частотах мод

ТЗ: [`memory/req-laplace-carriers-2026-09-20.md`](../req-laplace-carriers-2026-09-20.md);
preflight Researcher: [`memory/research/laplace-carriers-preflight-2026-09-20.json`](../research/laplace-carriers-preflight-2026-09-20.json).
Код запинен коммитом `cea5127`, каталог собран на нём.

## Что сделано

**Новый движок стенда `laplace_carriers` (label `Laplace waves`)** — `casynth_lab/laplace_carriers.py`.
Оба закона работают на ОДНОМ анализе: `analyse(grid, f0, 'laplacian', семь настроек, exc)` — те же
частоты и веса, что у существующего `laplacian`, та же геометрия, аудиочасы, фазы, огибающие
(`GEN_*` из `LegacySynthEngine`) и время отпускания.

- **Wave bank** — прежний `SlotPool` целиком (хвосты, ADSR, кроссфейды мод), заменена только волна
  слота: `W(theta; f) = sum_h c_h b(h f) sin(h theta)`. Sine идёт прямым `np.sin` → сумма мод
  побитово равна движку `laplacian` (проверено на всех 12 с Jam: 1488 блоков, diff 0).
- **Filter** — своя структура (`_FilterVoices`): один осциллятор на позицию голоса, частота `f0`,
  маска `H_k` по формуле ТЗ, масштаб `A = sqrt(sum a_j^2)`. Гармоники (K = 180 при f0 = 110 Hz)
  суммируются через кэшированные базисы `cos/sin(k*omega*i)` — четыре матричных умножения на блок
  вместо 180 синусов на голос.
- **Полоса** `b(nu)` (1 до 0.40·sr, косинусный спад, 0 на 0.45·sr) применяется к КАЖДОЙ волне по её
  собственной частоте. Saw/Square играются из полосно-ограниченной таблицы, построенной под точную
  частоту волны (TABLE_N 8192, линейная интерполяция, кэш 256 записей — попадание влияет только на
  скорость). Ошибка таблицы против прямой конечной суммы ≤ −76 dB (ТЗ требует −60).
- **Переходы**: любое изменение спектра (маска, волна, веса) глайдится за один блок по пуловой
  рампе `_RAMP`; смена метода — кроссфейд за `release_chunks` блоков (24 мс при 4 поколениях/с),
  повторное переключение разворачивает незаконченный кроссфейд, а не обрывает его.
- **Снимок** `STATE_VERSION 1`: массивы пула Wave bank (как у legacy) + фазы/амплитуды/спектры/
  огибающие/хвосты Filter + `mix` + предыдущая волна. Continue байт-в-байт, в том числе из середины
  поколения и из середины кроссфейда.
- Стенд: кнопки `Method` (Filter / Wave bank) и `Wave` (Sine / Saw / Square), `width` / `depth`
  показаны неактивными в Wave bank, `dyn` — «acts only with shape > 0»; панель движка (`display`)
  показывает закон, волну, число гармоник и голоса. `copy_spectrum` работает с `laplacian`
  (семь общих имён).

**Каталог** `lab_catalog/laplace_carriers_2026_09_20/` — шесть записей в порядке ТЗ (сначала четыре
сравнения с baseline, затем два сравнения методов), вход `run_laplace_carriers.bat`, гипотезы ТЗ в
Notes дословно. Поле — Jam из preflight, 32×32, тор, 4 поколения/с, 12 с, f0 110 Hz,
n 3 / spread 1 / alpha 0 / shape 0 / harm 0 / full 1 / dyn 0.

**Калибровка — один постоянный коэффициент на ВАРИАНТ, не на сцену** (ТЗ §5 «единые варианты»):
R 1.00, F-saw 0.89, F-square 0.97, W-saw 0.78, W-square 0.90. Так каждый вариант звучит побитово
одинаково во всех записях, где он встречается (проверено в отчёте). Разброс уровней готовых 12 с —
0.05 dB, пики ≤ 0.073, клипа нет.

**Отчёт измерений** `demos/results/laplace_carriers/report.{json,md}` (`python demos/laplace_carriers_report.py`).

## Проверено (сверх гейтов)

- Спектры: 48 поколений, 96 компонент, 240 мод — все пять вариантов читают один анализ; на трёх
  фазах preflight отклонение 0.
- Filter: коэффициенты первых 16 гармоник == preflight (худшее 5.6e−17), маска в dB == preflight
  (0), число ненулевых гармоник совпало для sine/saw/square; одна маска на Saw и Square; D = 0 ==
  чистая волна × A (1e−13); пустое поле и одна клетка молчат в обоих методах.
- Линии готовых дорожек: Filter — на `k*f0` (у Square чётные −55 dB и ниже), Wave bank — на `h*f_j`,
  включая нецелую моду 198.2 Hz; энергия выше 0.45·sr ≤ −91 dB.
- Бюджет: p99 обеих сторон 4.3–4.8 мс при бюджете 7.98; Continue точен во всех шести записях;
  replay каталога — match во всех шести.
- Гейты: `python check.py` — ALL GATES PASS (новый гейт 1r `tests/test_laplace_carriers.py`,
  34 теста). Старые аудиоэталоны и UI-кадр не трогались; в трёх тестах панели стенда обновлено
  ожидаемое число кнопок движков (15 → 16).

## Инженерные выборы (вынесены в `questions.md` для сверки Researcher)

1. Кроссфейд метода = время отпускания голосов; смена волны и маски — глайд за один блок.
2. Filter ведёт свои несущие (канал = позиция голоса), а не слоты пула: 180 гармоник не помещаются
   в 20 модовых слотов, и ТЗ прямо запрещает резать волну до старого размера массива мод.
   Следствие, предусмотренное ТЗ §4: пока фигура жива, смена её формы НЕ рождает хвостов и не
   ретриггерит огибающую (частота несущей не меняется) — переходы мягче, чем в baseline.
3. Sine рендерится прямым синусом (без таблицы) — это и есть побитовый baseline. `b(f)` применяется
   и к Sine, поэтому в полосе 0.40…0.45·sr Wave bank / Sine тише старого движка (у которого спада
   нет); на готовых сценах `b = 1`, различия нет.
4. Наблюдение к оценке результата: при трёх модах Filter звучит ТЕМНЕЕ baseline (спектральный
   центроид 141 / 120 Hz против 239 у R) — маска 24 dB оставляет из ряда пилы/меандра мало
   гармоник; Wave bank заметно ярче (695 / 517 Hz, 15 % / 8 % энергии выше 1 кГц против 0 % у R).
5. Пределы вне сцен: плотное случайное поле с n = 20 вне бюджета блока у всех трёх вариантов,
   включая baseline (`laplacian` p99 27 мс, Filter 22 мс, Wave bank 72 мс — последний дополнительно
   строит таблицу на каждую новую частоту моды).
