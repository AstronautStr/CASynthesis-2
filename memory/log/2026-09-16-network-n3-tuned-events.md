## Что сделано

0. Чекпойнты: `f2c236c` — каталоги опытов под контролем версий (записи, снапшоты, Notes; WAV в
   игноре); `9ffc509` — незакоммиченная память Researcher (ТЗ N3, preflight, ревью N2).
1. **Движок** `casynth_lab/tuned_events.py` (`ca_tuned_events`, кнопка «Tuned»,
   `model_version=ca_tuned_events_n3_v1`, `STATE_VERSION=1`). Одна модель, два режима ручки
   `field_tuning` (слова Fixed / Field). Сетевая часть = семпловая математика N2 Б без изменений
   (импульсы, задержки, матрица, фильтр потерь, tanh) при `rho=0.88` фиксированном; константы и
   `packet()/matrix()/pans()/consts()` импортируются из `event_network.py`, порядок операций ядра тот же —
   состояния сети равны `ca_event_network` побитово. Банки: 24 комплексных резонатора на узел (два
   вещественных массива, обе координаты из старых Re/Im), вход — значение фильтра потерь узла на
   этом отсчёте, `b_i = mean Re z'`, `r = 10^(−3/(SR·T60))`. Частоты: точный список
   `CONFIG['filters_hz']` N1 (8×24, не пересортирован) × `ratio_i = 2^(2u_i−1)` через
   `gf.ratio_of(u, 1, 1)` и `gf.bank_freqs` (float32-приведение как в А) — буквально закон А при
   scale 1 / depth 1; в Fixed все множители 1. Таблицы cos/sin считаются `math.cos/sin` по элементам
   (192 значения на перестройку) — референс тестов вычисляет те же числа. Панорама N2, HP 20 Гц на
   канал, ×4, gain стенда с косинусной рампой. Ручка `decay_s` («Decay» 0.20…1.50, дефолт 0.80):
   линейная рампа r за 882 отсчёта на семпл-пути; init — сразу настроенный r. Снапшот: сеть,
   Re/Im, `ffreq` (при restore пересчитывается из поля и параметров и сверяется — расхождение =
   ValueError), r и рампа, оба HP, `grid_prev`/`grid_pending`, `gain_prev`, `rho`, `out_scale`,
   версии. Хуки проверки: `raw_block(events=…)`, `inject(a)`, `network_state()`.
2. **Стенд** `demo_bench.py`: ветка `_draw_display` по ключу `tuning` (бары `a_i`, тик `max|b_i|`/5,
   `x{ratio}`, режим, decay и признак рампы); реестр 14 движков → по-прежнему 5 рядов (ассерт в
   `test_demo_lab_sn.py` поднят до 14). Оверлей — общий `periodic_readout.overlay`.
3. **Материал** `demos/build_n3_combined.py` → `demos/n3_{cycles,travel,growth}.json` +
   `lab_catalog/network_n3_combined_2026_09_16/` (3 записи, clip 0/0), `run_network_n3.bat` (экран
   каталога, без `--live`). Обе стороны — один движок на одном поле: А `field_tuning=0`,
   Б `field_tuning=1`, decay 0.8. N3.1: Octagon II (12,12) 12 с при 6 gen/s, затем **одна**
   команда `set_cells` всех 1024 клеток на `at=12·SR` → применяется на границе блока 529408
   (12.0047 с), в том же блоке причитающийся шаг КА (gen 72); аудиосостояния и часы не сбрасываются;
   ещё 12 с. Клетки всех фигур == fixtures preflight (проверено тестом); периоды 5 / 14 / 128.
   Гипотезы ТЗ в Notes дословно.
4. **Измерения** `demos/n3_combined_report.py` → `demos/results/network_n3/report.{json,md}`.
5. **Тесты** `tests/test_n3_tuned_events.py` — 16, гейт 1k в `check.py` (список — `tests/README.md` 4g).
   Главное: вся цепочка против независимого скалярного расчёта в обоих режимах и сквозь рампу decay
   с допуском 1e-12 (фактически совпадает до последнего бита в прогонах); состояния сети == N2.

## Измерения (`demos/results/network_n3/report.md`, коммит 5aea4f4)

- Сцены (стерео-RMS, как в preflight): все окна совпали с preflight Researcher до 0.1 dB —
  N3.1 octagon А −36.9 / Б −36.5, tumbler −38.1 / −37.5; N3.2 −37.6 / −37.7; N3.3 −34.9 / −33.9 dBFS;
  пики 0.054…0.105; разница А−Б < 1 dB в каждой сцене. Клипов/NaN нет. Хвосты после паузы КА
  (float): −50…−54 → −109…−116 → −155…−166 dBFS по секундам. p99 блока обеих сторон 0.75–1.7 мс.
- Замена в N3.1: 1 команда, 1024 клетки, отсчёт 529408, gen 72, пакет замены до 0.838.
- Continue: КА идёт (25/65/25 поколений за 4 с), обе стороны звучат; поздняя правка меняет звук
  на обеих сторонах (лог-спектральная дистанция 5–11 dB).
- Контрольные пробы: частоты удержаны / импульсы разные → отклики разные (дистанция 3.9 dB);
  импульсы удержаны / частоты разные → сети равны, отклики разные (4.7 dB); перестройка в нуле —
  ровно 0; возбуждённый хвост при перестройке сохраняет состояния и затухает без событий.
- **Стресс при gain 0.04, 6 с:** плотное случайное поле, случайное каждый блок, правки 5×5 на паузе,
  движение ручек — без клипа/NaN при T60 0.2 и 1.5. **«Всё поле каждый блок» при T60 1.5 с и Field:
  пик до клипа 1.157, 95–104 блоков с клипом** (T60 1.2 → 1.051, 1.0 → 1.007, дефолт 0.8 → 0;
  Fixed → 0.987, без клипа). Preflight давал 0.735 для этой пробы — там без шагов КА; здесь КА идёт
  (6 gen/s) поверх переключения. Коэффициент ×4 не менял (ТЗ: поправку согласовать) — вопрос в
  `questions.md`. Итог отчёта разделяет сцены и стресс и перечисляет ограничения (урок P2 N2).

## Отклонения / решения
- Метка кнопки движка — короткая ASCII «Tuned»; имена сторон ТЗ — в описании записи и `listen`.
- Дефолт `field_tuning` в реестре = 1 (движок назван по настройке); сцены задают явно.
- Тик уровня на панели = `max|b_i|`/5 (в сценах p90 ≈ 2.3–3.2, максимум ≈ 3–5).
- Замена поля в N3.1 листингом всех клеток (а не разницы): результат не зависит от фазы октагона
  в момент применения; запись журнала одна.
- Отчёт: RMS стерео (как preflight), в JSON также моно; окно tumbler сравнивается с preflight
  Tumbler «с нуля» — там нет хвоста октагона (оговорено в ограничениях).
