## Что сделано

1. **Ядро:** `casynth_core.laplacian_modes(..., return_index=False)` — при `True` дополнительно возвращает
   индексы выбранных мод в порядке собственных значений L (для собственных векторов именно этих мод);
   числа обоих прежних массивов от флага не зависят, `map_laplacian` и golden master побайтно прежние
   (`cd3126907ad13b6c`).
2. **Objects v4** (`ca_object_resonators_n4_v4`, `STATE_VERSION 4`; снимки v3/v2 принимаются как Both / Uniform
   (+ Attack 0 для v2) побитово):
   - ручка **Events** Both / Births / Deaths (default Both; отсутствие ключа = Both). Продолжающая фигура:
     `e = |B∩K_cur| + |D∩K_prev|` / `|B∩K_cur|` / `|D∩K_prev|`; новая фигура: Both/Births — рождения в K_cur,
     Deaths — без пакета; фигура, потерявшая идентичность (исчезла / split / merge): Both/Births — хвост без
     возбуждения (прежний цикл), **Deaths — один последний пакет смертей в прежней маске на прежних резонансах**:
     удар добавляется к импульсным состояниям банка, банк переносится в слот хвоста ВМЕСТЕ с ними (`_move_slot`,
     в т.ч. при вытеснении самого тихого хвоста), новый счётчик `npulse` = число прежних ведомых мод — хвост
     кормит их, пока все импульсные состояния не упадут ниже `TAIL_FLOOR` на границе блока (`_pulse_quiet` →
     `npulse 0`); повторного пакета нет (хвосты пакетов не получают). Стартовое заполнение поля: Both/Births —
     пакет из всех клеток, Deaths — ни одного. Переключение ручки пакета не создаёт.
   - ручка **Excitation** Uniform / Birth position (default Uniform). Uniform — прежний путь (a в состояния
     слота). Birth position определён для Events=Births, Own, Laplace, full=1 (`position_supported`); вне
     сочетания движок **не делает пакет** (счётчик `unsupported_packets`, строка стенда красным «no packets:
     needs Births / Own / Laplace / full») — общим ударом не подменяется. Закон: `birth_position_weights(L, idx,
     born)` — `p_j = Σ_{i∈B} Σ_{k∈Q(j)} φ_k(i)²/|Q(j)|`, группа Q по всему спектру с допуском
     `1e-8·max(1,|λ_j|)` (`degenerate_groups`), `b_j = sqrt(m·p_j/Σp)`, `Σp ≤ 1e-12` → b = 0 и счётчик
     `zero_participation`; `delta_j = a·b_j` добавляется в **состояния импульса моды j** (`zfm/zsm/zum` (S, M) —
     тот же импульс N2 и тот же Attack на каждой моде; при нулевых состояниях `p + 0.0 = p` — Uniform побитово
     прежний). Индексы мод — из `laplace_modes_of(..., with_graph=True)` (L канонического размещения, порядок
     узлов `order`, `idx`); собственные векторы — отдельный `eigh` той же матрицы. Новая мода при retune
     стартует без пакетной истории; исчезнувшая уносит состояния (обнуляются `_zero_modes`); выходные веса
     ударом не трогаются.
   - ядро `_render`: `nd = ndrive` для активного слота, `npulse` для хвоста; per-mode импульс только для
     j < nd. `display()`: `events/events_name`, `excitation/excitation_name`, `position_supported`,
     `position_condition`, `n_tails_fed`, `zero_participation`, `unsupported_packets`, у фигуры `b` (коэффициенты
     последнего пакета). Хуки тестов: `inject_modes(slot, deltas)`.
3. **Стенд:** `ROW_H 22→20` (16 строк панели + строки фигур должны влезать в 880 px); ширина кнопок выбора

## Открытые вопросы

- `memory/questions.md` — запись 2026-09-17 «Events / Birth position: три инженерных выбора Developer»:
  (а) стартовый пакет в Births = все клетки фигуры (в Birth position b = 1), в Deaths старта нет; (б) при
  split/merge в Birth position новые фигуры получают пространственный пакет по своим новым клеткам; (в) хвост
  Deaths при занятых пулах затухает на месте 20 мс вместе с последним ударом (прежнее правило in place);
  (г) кнопка Birth position доступна вне сочетания — движок молчит и показывает условие красным.
