## Что сделано

1. **`casynth_lab/scan_surface.py` — движок `scan_surface` («Scan»).** Поверхность
   `Smooth` (`2*gaussian_filter(g, sigma=width, mode='wrap') - 1`) / `Distance`
   (`tanh((d_dead - d_live)/width)`, евклидовы расстояния до ближайшего центра на торе через
   EDT на 3×3-замощении; пустое/полное поле = константы ∓1). Пути по ТЗ §3.2: Ellipse,
   Lissajous 2:3 (равномерная φ), Raster (змейка по всем центрам, постоянная скорость по
   длине, замыкание через шов кратчайшим отрезком: 1 при чётной H, √2 при нечётной; H=1/W=1
   без деления на ноль). Билинейное чтение в периодических координатах. Период читается в
   8192 фазовых точках (32×32; `table_size` = max(8192, 8·H·W до степени 2)), среднее
   удалено, сохраняются **комплексные** коэффициенты гармоник 1..K, K = ⌊0.45·sr/f0⌋ (180
   при 110 Гц, 45 при 440; K<1 → тишина). Рендер — **аддитивный из коэффициентов**
   (матрица гармоник рекуррентно через `cumprod`, ошибка ≤ 4e-13; ~0.7 мс/блок на сторону при
   двух волнах), ничего выше K не существует → отдельная внутренняя частота не нужна.
   Фаза — накопитель в циклах, никогда не сбрасывается; смена поля/поверхности/пути/радиусов
   → новый целевой вектор, линейный переход векторов за 882 сэмпла; правка посреди перехода
   стартует с реально достигнутой смеси. Gain/trim — глайд по `_RAMP` внутри блока (как у
   legacy). Сырой запас ×8 (|v| ≤ 2 → ≤ 0.64 FS при trim 0, переполнения нет). Snapshot:
   фаза, оба вектора коэффициентов, позиция перехода, предыдущий gain, params, K.
2. **`casynth_lab/pm_network.py` — движок `pm_network` («Network»).** Модель §4.1 буквально
   (i = 3,2,1,0, x_j того же сэмпла, без циклов), θ в циклах. Маски §4.2 (центры
   `(W-1)·[1/6,1/2,5/6]` × `(H-1)·[1/4,3/4]`, σ = min(H,W)/6, торовые расстояния),
   `W = ΣKg/ΣK/3`. Рендер 4× (`OVERSAMPLE`), полифазный Kaiser-FIR (β=8, 257 отводов,
   срез 0.476·sr = 21 кГц) с точной задержкой 32 выходных сэмпла (8× — 513 отводов, та же
   задержка), HPF 5 Гц первого порядка (`lfilter` с состоянием). W и beta — однополюсное
   сглаживание τ=30 мс в закрытой форме по блоку; gate «поле есть» 20 мс; frozen links
   держит достигнутую W (в snapshot), выключение — цель из текущего поля; начальный
   `freeze_links=1` фиксирует W стартовой сцены. Первые W при init — сразу из поля; фаза при
   правке не сбрасывается. Сырой запас ×8 (|raw| ≤ 1 → ≤ 0.32 FS). `display()` → шесть W,
   цели, frozen, gate. Snapshot: θ, W, W_target, frozen, beta, gate, память FIR (256),
   состояние HPF, gain_prev, params, раскладка рендера.
3. **Реестр/раннер/стенд.** `EngineSpec(..., choices, inactive, overlay)` — подсказки
   отображения без влияния на звук; `registry.value_text`, `describe_difference` словами
   («path: A=Ellipse, B=Lissajous»); `SideState.display()` → `runner.snapshot()['display']`.
   `demo_bench.py`: ряды кнопок движков и `params_y`/`footer_y` считаются из реестра (7
   движков → 3 ряда); кнопки-слова для `Surface`/`Path`; `Radius X/Y` = текст `Full field`
   при Raster (не кликабельны); оверлей выбранной стороны поверх клеток той же геометрией
   (`spec.overlay`): маршрут с точкой старта и стрелкой, шов Raster — два отрезка внутри поля
   (`_seam_pieces`), у Network — шесть кругов σ с метками `j>i`; полоски шести W (штрих =
   цель) под параметрами; окно выше на 20 px под подпись оверлея; вкладка с длинным именем
   движка — мелким шрифтом; **каталог: прокрутка колёсиком** (12 строк, «x–y of N»).
   UI-эталон `tests/golden/ui_frame.png` не затронут (он про `gol_synth.py`).
4. **Материал.** `demos/build_sn_demos.py`: поля F1–F5 + Kok's galaxy, 15 сцен
   `demos/sn_*.json` (клетки развёрнуты), каталог `lab_catalog/sn_demos_2026_09_14/{scan,network}/`
   — оффлайн-запись через тот же `Recorder`/`Catalog.save`, что и живой стенд; занятый целевой
   каталог → явная ошибка; `lab_catalog/local/` не трогается. Статичные записи: `start` +
   `pause on` в блоке 0 (running=True, paused=True, 0 поколений), 8 с; эволюция F3/Kok:
   12 с при 2 шагах/с. Порядок в каталоге = порядок шагов слухового ТЗ (сохранение в обратном
   порядке с паузой 1 с между записями). `run_scan_demo.bat` / `run_network_demo.bat`;
   `demos/README.md` (раздел + таблица), `tests/README.md` (§4d).
5. **Тесты.** `tests/test_demo_lab_sn.py` — 15 тестов (список в `tests/README.md` §4d),
   гейт 1g в `check.py`. `python check.py` → ALL GATES PASS (59+39+9+6+6+6+15, golden
   master без изменений, UI-кадр пиксель-в-пиксель).

## Отступления от ТЗ / выборы (вопрос в `questions.md` 2026-09-14)

- Два подкаталога `scan/` и `network/` вместо одного `sn_demos_2026_09_14/`.
- `rate_hz = 2` для эволюционных сцен (ТЗ не задаёт).
- Постоянные поправки уровня: **Scan +6 dB, Network +3 dB** — критерий: равный RMS с
  Laplace на F3 (12 с, с 1-й секунды; Laplace −18.3 dBFS RMS / пик −7.7). Стали дефолтами
  `trim_db` в реестре. Одна поправка на движок для всех сцен; никакой нормировки по записи.
- Рендер S без «более высокой внутренней частоты»: аддитивная оценка точна по построению;
  «удвоенная плотность» = 16384 vs 8192 точек чтения периода.
- Kok's galaxy добавлен как запись `N-frozen (Kok's galaxy)` — по резервному правилу ТЗ:
  ни Pulsar, ни галактика заметно не двигают W (см. ниже).

## Ограничения и что не входит

- Рисование ведёт к переходу 20 мс на каждую клетку (Scan) / движению W (Network) — это
  задуманное поведение, не артефакт; быстрые изменения звука при рисовании ожидаемы.
- Оверлей Scan кэшируется по параметрам; Raster = 1025 отрезков, рисуется `draw.lines`.
- Отображение W в панели — снимок раннера после блока (не синхронно с сэмплом, по ТЗ).
- Не входит: произвольная траектория, память поверхности, обратная связь N, другие
  сетки частот, MIDI, S8–S10, VST (по ТЗ §7).
