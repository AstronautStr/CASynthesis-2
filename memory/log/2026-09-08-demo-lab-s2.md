# 2026-09-08 — Demo lab S2: A/B comparison + engine parameters

REQ: `memory/req-demo-lab-s2.md`. S1 accepted by the user the same day (Stop button added

## What was built
- `casynth_lab/runner.py`: `DemoRunner` now owns ONE shared field + two `SideState`s
  (engine, params, SlotPool, phases, amps/pan, gain ramp, clip/peak).  `next_block()`
  renders both sides once per block and returns `Block(A, B, monitor)`; monitor = the
  listened side with a 20 ms linear crossfade (coefficients sum to 1) in the mixer only.
  New commands `select/set_param/set_engine` (side-addressed), validated against
  `casynth_core.ENGINES` at post() time (range/int/finite/unknown -> ValueError, state
  untouched; a queued engine change is taken into account).  Per (side x engine) param
  memory.  Engine change re-inits only that side's audio memory (no tail mixing) + a
  monitor fade-in when it is the listened side.  Stop/Restart reset both sides but keep
  engines/params/vol/selected side.  `render_offline(..., output='A'|'B'|'monitor'|tuple)`.
- `casynth_lab/scene.py`: format 2 (`variants` A/B, `listen`, `initial_side`); v1 loads as
  A = B; strict validation for both.
- `casynth_lab/audio_out.py`: sink hook gets `(monitor, Block)`; `post()` validates on the
  UI thread; status shows clip A/B separately.
- `demo_bench.py`: side panel with A/B tabs (listen + edit), engine buttons, registry knobs
  (sliders; 0/1 integer params as toggles), difference line via `describe_difference`,
  peak A/B, rejected-command message; `--side A|B|monitor` for offline.
- `demos/laplace_ab.json` (A harm=0, B harm=1); launcher opens it.  `demos/README.md`.
- `tests/test_demo_lab.py`: 33 tests (S1 adapted + S2).  `tests/golden/demo_lab_s1_ref.sha256`
  = hash of the S1-accepted 8 s render of laplace_basic (v1 PCM preserved, verified
  against artifacts/s1.wav byte-exact before hashing).

## Verification
- All five engines run on the demo scene, no NaN / clip; param memory per side x engine.
- A = B settings -> raw PCM identical; switching sides changes neither raw PCM nor field
  history; editing B leaves raw A byte-identical; laplace_ab A/B differ (max diff > 100 LSB),
  both non-silent, no clipping.
- Live (paced test sink, 2 batches) == offline for raw A, raw B and monitor on the S2
  scenario (select B, harm, engine FFT on B, cell edit, pause, select A, resume); journal
  times within one block of the requested times; repeat identical.
- Crossfade verified sample-wise (rint of linear mix, +-1 LSB), block count unchanged.
- CLI: all three outputs, bad scene messages.  Real device probe: 0 underruns through
  select/harm/engine actions.  `python check.py` ALL PASS (golden master untouched).

## Known limits
- Engine change on the listened side: old tails are dropped (hard), monitor fades in
  20 ms; the raw side PCM simply restarts.
- Slider is 120 px -> coarse for 0..20 integer knobs (ok for S2).
