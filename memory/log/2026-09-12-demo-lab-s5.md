## What was built
- **Engine interface** (`casynth_lab/engine_api.py`): optional `export_state()` /
  `restore_state(grid, exc, state)` + class `STATE_VERSION`; `supports_snapshot(engine)`.
  `LegacySynthEngine` (all five built-in methods, `STATE_VERSION = 1`) exports the
  explicit audio memory: `phase / amp_cur / pan_cur / gain_prev` + every `SlotPool`
  array (`freq_slots, amp_tgt, pan_tgt, _release_cnt, _release_amp0, _release_len,
  _freq_prev, _env_phase, _env_level, _amp_smooth`, steal diagnostics) + params;
  `voices` are NOT stored (pure function of grid/exc/params, recomputed by the same
  `analyse` call). Restore validates version / engine id / slot layout / shapes /
  finiteness, then overwrites fresh arrays in place (dtypes kept).
- **Runner** (`casynth_lab/runner.py`): `RUNNER_STATE_VERSION = 1`,
  `snapshot_support()`, `export_state()` (scene doc, ctx, grid, exc, gen, all three
  clocks, running/paused, vol, selected, mixer crossfade from/pos, `_seq`, pending
  commands with their `at`, per-side engine memory, per-side state incl. peak/clip
  diagnostics) and `DemoRunner.from_state()` (validates EVERYTHING first — scene, ctx
  vs SR/BLOCK/channels/f0/level/rate, grid/exc shapes, sides/params vs registry,
  pending kinds — then builds; nothing half-restored is returned). Journal starts
  empty; `out_samples` continues, so future `at` stamps stay valid.
- **Snapshot files** (`casynth_lab/snapshot.py`): state tree = JSON scalars + ndarrays
  → `<name>.json` + `<name>.npz` (dtype-exact, `allow_pickle=False`, object arrays
  refused, every referenced array checked); `copy_state()` for a pristine origin.
- **Recorder**: `origin_snapshot` / `parent_record_id`; a continued running runner
  starts recording AT the snapshot (`origin_kind='snapshot'`); a later Restart /
  Start-after-Stop → `origin_kind='fresh'` (parent link kept). Every cut carries
  `end_snapshot` (= `export_state()` at the cut boundary, render thread, after the
  block — never in the audio callback) or `end_snapshot_reason`.
- **Catalog**: `RECORD_FORMAT = 2` (reads 1 and 2; S4 records untouched, no
  migration, no fabricated snapshots). New meta: `origin_kind`, `parent_record_id`,
  `snapshot{runner_state_version, end{json,npz}|None, end_reason, origin{...}|None,
  origin_seq, engine_state_versions}`; files `state_end.*` and (branches)
  `state_origin.*` written inside the `.partial` dir → atomic as before.
  `Record.can_continue()` (engines registered → snapshot present → version → files),
  `Catalog.parent_of()`, `end_state()`, `continue_runner(rid)` → (runner, pristine
  state, record). `replay()` routes snapshot-origin records through
  `from_state(origin)` with ABSOLUTE times and skips journal entries with
  `seq <= origin_seq` (those were queued inside the snapshot and are re-applied by
  the runner itself — never twice).
- **LiveEngine**: `origin_snapshot` / `parent_record_id` pass-through to the Recorder.
- **UI** (`demo_bench.py`): catalog actions **Continue** (main; "Continue
  unavailable: <why>" when not offered), **Open field anew** (= former Open in bench,
  fresh sound, CA paused, parent link kept), **Check reproducibility** (= former
  Replay from start), **Derived from: <title>** link (click → selects the parent;
  "(missing)" when gone), list tag `branch`. `replace_session()` now accepts a
  restored runner. Continue validates before swapping; on failure the current
  session stays and the status explains.
- **Runner fix found on the way:** `select` / `set_engine` / `copy` / `factory` on a
  NOT running scene used to arm a mixer crossfade that lay dormant until Start and
  then faded the first 20 ms → a fresh-conditions replay (no mixer memory) could
  differ on `monitor`. Now `_begin_xfade` is a no-op while not running (nothing to
  fade from). S1–S4 references unchanged.
- Tests: `tests/test_demo_lab_s5.py` (6 tests, `check.py` gate 1d): continuity for the
  five engines in-process + fresh process with the same post-snapshot command set
  (paint, params, engine switch + memory, copy, select, vol, pause, factory, stop,
  start, restart); hard boundaries (inside the A/B crossfade, ringing tails, block
  before a CA step, Pause CA, Stop, mixed engines, param change, scheduled command;
  export twice = same, export changes nothing in the live session, restore twice =
  identical); branch flow (parent → continue → change → save → replay in-process +
  child process → parent folder hidden: replay/list/continue still fine → continue
  parent again = same first blocks → continue the branch → grandchild's parent =
  branch); Stop/Restart after continue (fresh origin, parent kept, bounded window);
  compatibility + errors (S4-style record, truncated npz, wrong version, wrong grid /
  array shapes, engine without snapshot support incl. unregistered later, simulated
  save failure, object arrays refused); headless UI (Continue, branch save, Derived
  from link, Check reproducibility = "Replay matched", continue parent again → harm
  0.25, Open field anew, refused Continue keeps the session).
- S4 test hygiene: ids created within one second sort by their random suffix →
  lookups by id instead of list index (pre-existing flake); tracebacks on failure.
