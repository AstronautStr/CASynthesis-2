## Design points (engineering, S1 scope)
- Clocks in samples: `out_samples` (transport, monotone, command timestamps),
  `t_samples` (scene audio), `ca_samples` (frozen by pause -> no catch-up). Step when
  `ca_samples >= (gen+1)*SR/rate` checked once per block -> within one block boundary.
- Commands apply at first block boundary >= `at`; order = (at, seq). Reset clears the
  pending queue and reinitialises all state, then runs.
- Edit recomputes exc via `events_field(prev, new)` (paint = birth, erase = wound edge)
  and re-analyses; dyn=0 in S1 so exc has no audible effect yet.
- GEN A/D/R fractions -> chunks as in gol_synth (`max(1, round(frac*interval/CHUNK_S))`),
  amp_slew False, VOICE VCA = 1 (open), transpose 1.0, pan forced 0.5 (L == R).
- Baseline gates before work: ALL PASS; unchanged after (golden master not touched).

## Known limits
- Reset transport = hard flush of queued blocks + fade-in (no fade-out of the residual
  partial block, <= 8 ms). Underrun counter counts callback starvation.
- Journal is in-memory only (S4 persistence). UI labels are English (ASCII) for now.
