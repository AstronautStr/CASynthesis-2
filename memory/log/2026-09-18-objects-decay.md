## Что сделано

1. **Objects v6** (`ca_object_resonators_n4_v6`, `STATE_VERSION 6`):
   - ручка **Decay law** `decay_law` 0/1/2 = Fixed / Common age / Modal age (кнопки Fixed / Common / Modal —
     полные имена не помещаются в три кнопки по 60 px; полные — в `LAW_NAMES`, шапке и `display`), сразу после Decay;
     отсутствие ключа = Fixed.
   - **история:** `age` на каждую позицию поля: рождение → 1, смерть → 0, выжившие хранят; после каждого
     отрендеренного блока `×exp(−352/(44100·0.5))` — по аудиочасам, и во время паузы КА. Переход — та же разность
     G_prev → G на границе рендера, что у возбуждения (несколько правок до рендера схлопываются). Обновляется и в Fixed.
   - **цели:** `mode_participation(L, idx)` — квадраты собственных векторов полного торового графа, усреднённые
     по кратной группе (`DEGEN_TOL` по всему спектру, строки суммируются в 1); `age_targets`: q = P·u (клип в [0,1]
     в пределах 1e−9, за 1e−6 — ошибка), T = Decay − (Decay − 0.08)·q, gamma = ln1000/T; Common = средняя
     СКОРОСТЬ. Цели — на каждой границе блока (`_refresh_targets`).
   - **ядро:** слот с `slaw = 1` на каждый сэмпл и моду `ga ← k·ga + (1−k)·gt`, `k = exp(−1/(SR·0.020))`,
     `r_j = exp(−ga/SR)` вместо общего r; слоты `slaw = 0` — прежняя арифметика (Fixed побайтно).
   - **жизненный цикл:** новый слот / новая мода стартуют с `ga = gt`; продолжающаяся мода хранит `ga`; хвосты
     (`_move_slot`, `_split_tail`, затухание на месте) уносят `gam_a/gam_t/slaw` и держат последнюю цель;
     переход Fixed → адаптивный: все занятые слоты стартуют с gamma текущего r, активные получают цели на границе,
     хвосты эпохи Fixed держат Decay момента переключения (ТЗ: «отделённые хвосты заканчиваются по сохранённому
     закону»); адаптивный → Fixed: активные банки целятся в фиксированную gamma и возвращаются к общему r, когда
     сошлись и рампа r закончена (`_settle_fixed`). Смена закона/Decay — без пакета и без сброса.
   - **снимок v6:** `age`, `slaw/gam_a/gam_t`, кэш P активных фигур (`fig_part*`), `law_key`; снимок v5 → Fixed,
     u = 1 на живых клетках прежнего поля (тот же звук); отказы: версия/модель, недопустимое сочетание,
     возраст вне [0,1] или на мёртвой клетке, закон у свободного слота, отрицательные/нулевые скорости.
   - **стоимость:** P кэшируется на фигуру и по канонической форме (`pshape`, до 4096 форм); под адаптивным законом
     вызов частот отдаёт свой граф (те же числа, на один eigvalsh меньше). Разложения — только при новой форме.
2. **Правило сочетания** (адаптивный закон только при Spectrum Laplace + full): новый хук реестра
   `EngineSpec.validate` / `registry.validate_params`; проверяют движок (конструктор, `set_params` — параметры не
   меняются), загрузчик сцены, снимок (раннер и движок), раннер при постановке `set_param` / `copy_spectrum`
   (с учётом ещё не применённых команд — `_params_when_applied`); отказ на применении не журналируется. Стенд
   блокирует обе стороны: при Figure/8x8 кнопки закона — текст «Fixed  (needs Laplace + full)», при адаптивном
   законе Spectrum и full — «… held by Decay law».
3. **Ключ сцены `script`** (новое, необязательное): команды `pause` по часам сцены; раннер ставит их при каждом
   старте сцены с начала (Start, отпускание паузы остановленной сцены, Restart) — так паузы D2 есть и в записи,
   и при живом Restart. В журнале они помечены `script`; реплей каталога их пропускает (`catalog._replayed`),
   потому что воспроизведённый старт ставит их снова; Continue с конечного снимка их не повторяет.
4. **Стенд:** `ROW_H 17` (18 строк панели, окно 872 px при столе 960), `RANGE_FIELD_H 17`, зона клика слайдера

   R x только при Disk, закон спектра, `decay d s` / Common / Modal, `*` = рампа; прежняя строка 349 px уходила
   под колонку Patterns), четвёртая строка при адаптивном законе — `decay_law_line` («Modal age  stable 1.39 s;
   rows: target T»), строка фигуры — `T lo-hi s` (`figure_decay_text`). Проверено глазами на D2/D3.
5. **Сцены:** все 12 прежних Objects-сцен несут `decay_law: 0` (звук тот же, записи их каталогов на своих коммитах);
   новые `demos/od_d{1,2,3}.json`, сборщик `demos/build_objects_decay.py`, `run_objects_decay.bat`.
6. **Каталог** `lab_catalog/objects_decay_2026_09_18/` — D1, D2, D3, Notes = гипотезы ТЗ дословно, описание
   записи — условия; запинен на `1fdf8d1`, реплей match у всех трёх.

## Измерения (`demos/results/objects_decay/report.md`, коммит `1fdf8d1`)

- **Цели против preflight:** D1 40, D2 26 (22 перехода + 4 границы пауз), D3 324 банка на переходах — Common и
  Modal, max |T − preflight| ≤ 2.2e−16 s, частоты ≤ 8e−13 Hz. Возраст движка == независимая модель по блокам
  (шов, повторное рождение, пауза, правки в одном блоке, restore).
- **D1:** средняя целевая gamma Б за 5…20 с 7.2872 1/s против контроля ln1000/0.947926 = 7.2872 (0.00 %),
  применённая — 0.00 %. По фазам зрелого цикла: цель на шаге 0.735 / 0.650 / 0.415 / 1.154 / 0.852 с, средняя
  ПРИМЕНЁННАЯ T за интервал 0.959 / 0.905 / 0.732 / 1.232 / 1.054 с (max/min 1.68). T60 по PCM между шагами:
  Б 0.973 / 0.922 / 0.710 / — / 1.063 с (в пределах 3 % от применённой), А 0.941–0.942 с во всех фазах (0.8 % от
  контроля). Фаза без рождений (новых ударов нет) в PCM не измерима: хвост прошлого интервала к ней уже у младших
  разрядов int16. **Наблюдение для Researcher:** свежесть убывает за 0.5 с между поколениями, поэтому средняя T
  хвоста в каждой фазе заметно длиннее цели в момент шага (0.73–1.23 против 0.41–1.15 с); контраст фаз в звуке
  ≈ ×1.5–1.7, не ×2.8, как у чисел на шагах.
- **D2 (настоящий движок, обе паузы):** от первой границы блока паузы верх − низ за 0.104 / 0.247 / 0.503 с:

## Инженерные выборы (не дизайн; вопрос на сверку — `questions.md`)

- Кнопки Common / Modal вместо полных имён (ширина), полные имена — в шапке и `display`.
- Хвосты эпохи Fixed при переходе на адаптивный закон фиксируют Decay момента переключения.
- Паузы D2 — ключом сцены `script`, а не только командами журнала: иначе Restart в живом окне их бы не повторил.
- Реплей каталога пропускает команды с пометкой `script` (для старых записей ничего не меняется: пометок нет).
- Вторая строка шапки Objects перестроена (без легенды «a | level», рампа — `*`), чтобы ничего не уходило под колонку
  Patterns.
