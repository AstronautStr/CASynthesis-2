# 2026-09-16 — Demo-стенд: единая модель текстовых полей, кнопка Clear, библиотека паттернов

Запрос Пользователя: в поле Notes нельзя было кликом/стрелками двигать курсор и выделять
текст; самописные инпут-филды уже кусали — требуемое поведение должно распространяться на
ВСЕ поля; нужна кнопка стирания поля КА; нужен каталог форм Жизни с drag-n-drop на поле,
как в синте. Три коммита на `master` (один на фичу).

## 1. `clear` / `set_cells` в раннере + кнопка Clear (C)
- `casynth_lab/runner.py`: команды `clear` (пустое поле; транспорт/движки/параметры не
  трогает) и `set_cells` (список `[[r, c, v], …]` одной командой: одно поле событий, одно
  обновление движков, одна JSON-запись журнала). Валидация в `_check` до изменения
  состояния (вне поля → `ValueError`). Реплей из журнала — как у любой команды.
- Раннер — в ЗВУКОВОМ наборе отпечатка; перепривязка записей честная, и она всё равно уже
  случилась незакоммиченной работой N1 (`gutter_controls.py` в реестре).
- `demo_bench.py`: четвёртая транспортная кнопка Clear (C); ширина окна = max(панель,
  верхний ряд). Старые версии стенда не знают новых команд (записи с ними в старой версии
  не реплеятся — ожидаемо).

## 2. Одна модель для всех текстовых полей — `casynth_lab/textedit.py`
- `TextEdit` (pygame-free; метрики текста подаёт вид): текст, каретка, якорь выделения,
  правило слова S4 для Ctrl+Backspace/Ctrl+стрелки («заметка  два » ← «заметка  два три »),
  перенос по ширине с сохранением индексов (`layout` → спаны визуальных строк, кэш по
  тексту/ширине/метрике), `index_at` (пиксель → индекс, бинарный поиск), `move_lines`
  с липкой колонкой (`goal_x`), Home/End по визуальной строке, `scroll`/`follow`
  (вид следует за кареткой после правки, колесо не сбивается).
- `demo_bench.py`: единый маршрут для форм Save (Title/Note) и Notes — `_active_edit` /
  `_edit_key` (Backspace/Delete ± Ctrl, стрелки ± Shift/Ctrl, Home/End, Up/Down,
  Ctrl+A/X/C/V) / `_caret_from_pos` (клик ставит каретку, drag и Shift+клик выделяют) /
  `_draw_edit` (выделение, текст, каретка; однострочное поле скроллит по пикселям,
  многострочное — по строкам). Метрики берутся из шрифта при первом `draw`
  (`_bind_font`); до него — 7 px/символ (тесты). Буфер обмена: `pygame.scrap` после
  `set_mode`, иначе внутренний. Колесо над Notes — прокрутка текста. Главный цикл передаёт
  Shift и MOUSEWHEEL. Строки форм (`save_form['title']`, `notes_form['text']`) остаются
  зеркалом модели — контракты тестов S4/S-N не менялись.
- `textedit.py` добавлен в `SOUND_EXCLUDE` (не влияет на звук).

## 3. Библиотека паттернов + drag-n-drop
- Колонка «Patterns» справа от панели (`LIB_*` константы; `patterns.py` — те же 29 форм в
  9 категориях, что у синта), превью и заголовки категорий, прокрутка колесом с ползунком.
- Нажатие на элемент → `drag_pat`; движение над полем — призрак (`C_GHOST`, торовый
  перенос) + имя; отпускание — `stamp()` → одна команда `set_cells`; отпускание вне поля
  или Esc — отмена (Esc в живом режиме больше не закрывает окно, пока тянется паттерн).
  Клики вне окна Notes по-прежнему доходят до библиотеки.
