# 2026-09-09 — Demo lab S3: sound-engine interface + bench registry

REQ: `memory/req-demo-lab-s3.md` (replaces the old "S3 = new engine with memory" pointer).
S2 accepted the same day.

## What was built
- `casynth_lab/engine_api.py`: `EngineContext` (sr, block, channels, f0, level, rate_hz),
  `SoundEngine` base (`init(grid, exc, gain)`, `update_field`, `set_params`,
  `render(gain, t_samples) -> (int16 (block,2), peak, n_clip)`, `reset(gain)`),
  `check_block` / `EngineBlockError`.
- `casynth_lab/legacy_engine.py`: `LegacySynthEngine` = the former SideState internals
  (analyse -> SlotPool.update -> render_chunk_laplacian, GEN chunk counts from rate_hz,
  pan 0.5) behind the interface; partials/SlotPool/phases stay inside the adapter.
- `casynth_lab/registry.py`: `EngineSpec(id, label, params, factory)`, `register/unregister/
  get/ids/specs/label/defaults/create/validate_param`; the five casynth_core engines are
  registered from `casynth_core.ENGINES` (metadata not duplicated).
- `runner.py`: `SideState` holds an engine INSTANCE (create/switch/restart/set_params/
  update_field/render + block validation); `scene.py` / `demo_bench.py` read the registry.
- `audio_out.py`: a malformed block (EngineBlockError) is replaced by silence, counted and
  shown as "ENGINE ERROR" in the status.
- `demos/README.md`: how to add + register an engine and reference it from JSON.

## Verification
- `tests/golden/demo_lab_s2_ref.{py,json}`: hashes of raw A / raw B / monitor for the five
  engines on a fixed journal (painting, param, pause, vol, select, copy), recorded from the
  accepted S2 commit BEFORE the refactor -> byte-identical after (test in the suite).
  `demo_lab_s1_ref.sha256` unchanged and still passing.
- Alias registration of the adapter (`laplacian_alias`): scene validation, commands,
  offline render (== laplacian PCM) and the headless UI use it with no code changes;
  unregistering makes the scene loader reject it.
- Test-only stub engine with a known PCM pattern passes through raw B and the monitor
  untouched, side A unaffected; the bench never touched SlotPool for it.
- Bad block (wrong shape/dtype): DemoRunner raises; LiveEngine emits silence + counter.
- All S1/S2 scenarios (independence, monitor, reset, live == offline) pass through the
  interface: 39 tests; `python check.py` ALL PASS; real-device smoke through all five
  engines: 0 underruns.

## Limits
- `gol_synth.py` still uses the DSP library directly (not ported to the interface, per REQ).
- Registration is explicit in `registry.py`; no plugin discovery.
