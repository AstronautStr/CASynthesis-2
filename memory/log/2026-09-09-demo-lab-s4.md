# 2026-09-09 — Demo lab S4: local experiment catalog + replay from start

REQ: `memory/req-demo-lab-s4.md`.

## What was built
- `casynth_lab/recorder.py`: `Recorder` streams every rendered Block (raw A / raw B /
  monitor) to raw PCM files in `lab_catalog/local/.tmp/<session>/` from the render thread
  (never the audio callback); recording starts with the first RUNNING block
  (`audio_start_sample`); `cut()` = consistent interval (end at a completed block boundary,
  applied journal `< end`, byte counts, embedded scene doc, initial vol, diagnostics).
- `casynth_lab/catalog.py`: `Catalog(root)` — `save(cut, title, note)` assembles WAVs
  (streaming, sha256) + `record.json` in `<id>.partial/` and renames atomically (retry on
  Windows transient PermissionError); `list()` tolerates broken records; `Record.pcm()`;
  `replay(id, progress, cancel)` rebuilds a DemoRunner from the embedded scene and feeds the
  journal boundary by boundary (so Stop/Restart do not drop later commands; `step` entries
  skipped), compares byte-exact -> `ReplayResult` match / mismatch / unavailable / cancelled,
  writes `<id>/replay/*.wav`, originals untouched.  `replay_in_subprocess()` + CLI
  `python -m casynth_lab.catalog replay ROOT ID` (JSON lines) — used by the UI because an
  in-process replay starves the audio callback of the GIL (measured 10–27 underruns
  in-process, 0 in a child process).
- `audio_out.py`: `record_root` -> Recorder; `request_cut()/take_cut()/cut_now()`;
  `play_pcm()/stop_play()` — record playback through the SAME callback, live blocks drained
  (experiment keeps running) but muted: record and synth never sound together;
  `diagnostics()`.
- `demo_bench.py`: Save / Catalog buttons; save form (title default = demo title + time,
  note, Tab/Enter/Esc, TEXTINPUT incl. Cyrillic; hotkeys inert while typing); catalog view
  (list newest first: title, date, duration, engines A/B, Local; Play A/B/as heard, Stop,
  Replay from start with progress + Cancel, Play replay, Back/Esc); status line.
- `scene.py`: `Scene.doc` (deep copy) + `scene_from_doc()`; `.gitignore`: `lab_catalog/`.
- `tests/test_demo_lab_s4.py` (7 tests) as a `check.py` gate; `demos/README.md` section.

## Verification
- Fixed experiment (settings before Start, painting, B engine/param, vol, A/B, pause,
  Stop/Start, Restart, copy, factory; commands drip-fed like the UI) saved with Cyrillic
  title/note, loaded + replayed in a fresh process: A/B/monitor byte-exact, journal contains
  the post-Stop/Restart commands, saved WAVs == the sink's blocks for the interval.
- Cut = consistent prefix (future/pending commands excluded), session continues, second save
  = new id, first unchanged; waiting before Start does not lengthen the WAV.
- Source JSON deleted -> replay from embedded scene OK; engine unregistered -> WAV still
  readable/playable, replay "unavailable: unknown engine"; interrupted recording / disk
  failure -> CatalogError, no partial dir, older records intact; corrupted record.json /
  truncated WAV -> listed as broken / replay explains; altered WAV -> "differs", original kept.
- Headless UI: save-before-start message, save form, catalog list/select, play (device gets
  the record PCM, live muted), stop, replay -> "Replay matched", play replay, Esc.
- `python check.py` ALL PASS (S1–S3 references untouched); real-device smoke: record, save,
  play, subprocess replay -> 0 underruns.
