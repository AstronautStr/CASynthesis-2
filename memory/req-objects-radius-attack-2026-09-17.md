## 1. Ручной диапазон Radius x

Рядом с ползунком два редактируемых числовых поля **Min / Max**, по умолчанию **0.25 / 4**. Слайдер линейный: `radius_mul = min + t·(max−min)`, t от 0 до 1. Пользователь может задать узкий интервал, например 0.30…0.60, или широкий, например 1…32. Шаги 0.01–0.02 должны быть различимы и доступны; значение показывать с достаточной точностью.

Диапазон относится к выбранной стороне. Коммит ввода — Enter/выход из поля; Esc отменяет. Принимать конечные числа `0 ≤ min < max`; незавершённое/ошибочное число не менять в действующей настройке, показать ошибку у поля. Если подтверждённый диапазон исключает текущий radius_mul, один раз прижать его к ближайшей границе. Смена диапазона без изменения radius_mul не меняет звук; смена самого radius_mul не создаёт импульса.

Убрать технический потолок 4 из валидации действительного радиуса. Отдельного нового произвольного потолка вроде 8/32 не вводить: допускаются конечные неотрицательные значения. Не изменять общий реестр параметров при редактировании границ одной стороны. Границы и значение сохраняются в сцене/опыте/Continue; старые записи без границ получают 0.25/4. `Own` продолжает игнорировать радиус. Размещение состояния UI и способ расширения валидации — Developer.

Считать прежнее `R_eff=radius_mul·R_geom`; спектр и геометрический R не изменяются. На торе большие радиусы в итоге охватывают всё поле: использовать эквивалентную полную маску без переполнения при умножении/квадрате. R=0 остаётся нулём. Если круг охватывает всё поле, отобразить это понятно, даже когда его контур ушёл за экран. Картинка и аудиомаска должны соответствовать друг другу.

## 2. Attack для импульса возбуждения

Добавить **Attack, ms: 0…20, default 0** в Objects, для обоих режимов спектра. Это сглаживание начала возбуждающего импульса. Decay по-прежнему управляет затуханием резонаторов. Моменты/число событий, `a=e/(e+2)`, настройку резонансов и веса не менять.

Для первой пробы — один причинный сглаживающий фильтр перед входом банка. Если `p[k]` — существующий импульс:

```text
Attack = 0: u[k] = p[k]                       # прежний семпловый тракт
Attack > 0:
    q = exp(-ln(9) / (SR * Attack_ms / 1000))
    u[k] = q * u[k-1] + (1-q) * p[k]
```

Attack здесь — время 10→90% ступенчатого отклика сглаживания; не обещание измеренного времени атаки каждой слышимой ноты. Состояние `u` отдельное для каждого банка. В реальном времени изменение коэффициента сгладить за 20 ms; не сбрасывать резонаторы и не перезапускать ноту. При переходе через ноль сохранять корректное состояние; при нуле после завершения перехода — точный прежний тракт. Состояние фильтра/переходов включить в snapshot и правила освобождения голосов. Старый снимок без Attack означает 0. Если после исчезновения фигуры банк стал хвостом, правило отсутствия новых возбуждений сохраняется.

Не добавлять автоматическую компенсацию громкости при вращении Attack. Фильтр меняет яркость и уровень — это показать в сравнении и описать коротко, а не объявлять неизменным тембром. Ручка не устраняет клип и underruns; такие сбои проверять отдельно.

## 3. Три подготовленных А/Б опыта

Новый каталог `lab_catalog/objects_radius_attack_2026_09_17/`, вход `run_objects_radius_attack.bat`. В обоих сторонах **Objects / Laplace**, одинаковое поле и настройки. Это локальное сравнение радиуса/атаки; прежний каталог Laplace/Objects сохраняется.

Общие настройки из скриншота: Disk; Decay=1.39, part=3, spread=1, alpha=1.82, shape=0.95, harm=0.87, full=1, dyn=0.87. f0=110 Hz, 6 поколений/с, 32×32 тор, B3/S23, 12 секунд. Radius/Attack задаются опытом. Пользовательскую настройку Radius=0.34 сохранить отдельным доступным пресетом с остальными значениями скриншота; не подменять ею радиусные А/Б.

**R1 — «Сосед возбуждает неподвижную фигуру».** Клетки `cases.receiver.groups` из preflight: неподвижная 17-клеточная фигура и блинкер `(9,17),(9,18),(9,19)`. А: Radius=1; Б: Radius=2; Attack=0 с обеих сторон. Блинкер продолжает звучать в А и Б. После стартового хвоста приёмник в А не получает пакетов, в Б принимает четыре чужих изменения за поколение.

Notes: **Гипотеза - В А после стартового хвоста остаётся блинкер; в Б его изменения должны дополнительно возбуждать неподвижную соседнюю фигуру. Ожидаем дополнительный повторяющийся резонансный отклик при той же работе блинкера. Проверяем, слышно ли появление второго голоса при расширении круга.**

**R2 — «Два периода: самостоятельные и общий приём».** Клетки `cases.p3_p5.groups`: Jam p3 от `(5,3)` и Octagon II p5 от `(17,19)`. А: Radius=1; Б: Radius=32; Attack=0. Диапазон ползунка 0.25…32. При ×1 между двумя семействами нет приёма событий; при ×32 все звучащие компоненты принимают изменения всего поля. ×8 — проверенное промежуточное положение для игры, отдельный опыт не нужен. Под «семействами» здесь два размещённых осциллятора КА; Jam в отдельных фазах состоит из нескольких связных компонент/банков.

Notes: **Гипотеза - В А два осциллятора сохраняют свои области приёма. В Б события каждого должны возбуждать также банки второго, поэтому ожидаем больше общих акцентов и более плотное наложение звуков. Проверяем, слышно ли взаимное влияние и остаются ли различимы два ритмических рисунка; очень большой радиус может сделать их менее самостоятельными.**

**A1 — «Резкость возбуждения».** То же поле и Radius=32 с обеих сторон. А: Attack=0; Б: Attack=4 ms. Все события и спектральные настройки одинаковы. Сравнивается текущий импульс с предложенным сглаживанием, предварительно проверить реализацию и уровень.

Notes: **Гипотеза - При тех же моментах возбуждения в Б начало звуков станет мягче и менее щёлкающим, а в А останется нынешняя резкая атака. Ожидаем также изменение яркости. Проверяем, помогает ли атака сохранить интересный рисунок при плотном взаимном возбуждении и сделать его удобнее для игры.**

Во всех парах выровнять RMS готовых 12 секунд одной постоянной `audio.side_gain` до разницы ≤1 dB, поправка не меняется при игре. В preflight R1 Б громче на 3.80 dB, R2 Б на 3.26 dB; это исходные числа для калибровки, не готовые коэффициенты после реализации. Для A1 измерить заново; отсутствие клипа проверить после компенсации. Не менять индивидуальные тембровые ручки для получения контраста.
